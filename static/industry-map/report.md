# 泉州工厂业务链与 KANPACE 产品规划

调研日期：2026-09-07。面向 KANPACE 产品决策、工厂老板访谈及首单实施。

## 直接结论

KANPACE 应先做好“把已确认的订单与技术资料，变成工人拿到就知道做什么的图文任务，并追踪跨工种交接”。第一批优先验证展柜既有业务，以及安溪藤铁木作、南安石材工程、泉州专用机械这三种邻近场景。这个排序依据现有产品能力的复用程度，尚未经过客户付费意愿验证。

本次沿用户提供的《泉州产业调研2607_V2.html》研究九大产业领域，进一步区分为 19 类工厂业务场景。官方研究也采用县域细分产业链口径：泉州对 13 个县域梳理了 50 条重点产业链。因此，产业集群名称适合市场地图，配置软件还要细到工厂实际承担的制造环节。[泉州市科技局，2024-11-05](https://kj.quanzhou.gov.cn/xxgk/kjxw/202411/t20241105_3101227.htm)

本报告与配套图谱是桌面研究和产品建模建议。没有访问工厂现场，没有得到完整的现行 SOP、真实工时、客户付费结果，也没有把这些行业模板自动安装到任何客户空间。用户原文件的 GDP、产值、份额、企业数未逐项核验；不同年份、规上/全口径、产业链/工业产值不用于相加或计算本产品市场规模。

## 一、先按实际工作对象组织软件

| 组织方式 | 代表业务 | 系统必须认清什么 | 适合优先提供什么 |
|---|---|---|---|
| 工程与装配 | 展柜、藤铁家居、机械、石材工程 | 项目、柜/部套/板件、图号、版本、安装位置 | 图文交底、按对象齐套、外协交接、分批交付 |
| 款式与工序流水 | 成鞋、成衣、纸盒印刷 | 款色码、扎包、签样版次、工序批 | 正确版本到工位、配套缺口、批量转序、返修 |
| 批次加工与装配 | 染整、陶瓷、食品、茶、香、卫浴 | 配方/模具、投入批、产出批、窑次/缸号、合格数量 | 批次流转、准备和等待、质量放行、数量交接 |
| 连续或专用制造 | 建陶、原纸、卫生用品、石化、半导体 | 线体/设备、时段、换型、卷/批、原系统的过程状态 | 先接异常、维修、换型、交班及已有系统状态 |

这些是可组合的业务模型。一个智能卫浴厂可能同时有陶瓷批次、采购模块和整机装配；不能强迫全厂只选一种对象。半导体前道与电子装配分别建模，石化生产与设备检维修也分别建模。19 类详细路线、来源、输入资料、卡点、建议指标及硬件入口见配套图谱和 JSON 数据。

## 二、先替代一个付得起钱的人工环节

现有流程常见的一段是：技术员找图、裁图、抄清单 → 按工种重新做表 → 发群或打印 → 工人问位置、做法和版本 → 主管追进度并补 Excel。

建议首个交付闭环：接收已确认资料 → 对齐对象/编号/版本 → 生成分工草稿与缺项 → 技术员确认 → 每个岗位收到一张图文任务卡 → 暂停/换单/交接/验收 → 写回原表。

每张任务卡只需要：项目和对象、当前要做的动作、相关局部图、明确数量与单位、关键要求、预计完成/交接对象，以及开始、暂停、报问题、完成数量等当前可用操作。整体效果图作为可点开的定位参照。图纸缺制造信息时，形成“深化确认”待办，不能猜出尺寸后发生产任务。

机械行业已有公开参照：铁拓机械 2025 ESG 报告披露了设计资料按工序、班组分发到车间，以及图纸问题回流设计的做法。大型厂可能已具备 PLM，KANPACE 应接其发布结果，再补现场交接。[铁拓机械报告，第19–20页，2026-04-14披露路径](https://static.cninfo.com.cn/finalpage/2026-04-14/1225102146.PDF)

石材行业亦已有扫描、数字排版和生产管理系统，不能把“能看三维”当独有能力。优先补加工单到板件、包装箱与安装位置之间的交接缺口。[泉州市工信局，2021-05-26](https://gxj.quanzhou.gov.cn/zwgk/gzdt/202105/t20210526_2563618.htm)

电子客户也不能假设没有系统。科立讯于 2025-06-20 公布 IMS-WMES 二期启动；这证明有既有系统的场景存在，但不证明对外 API 开放或项目已验收。[科立讯官方公告](https://www.kirisun.com/kirisun-launches-phase-II-of-IMS-WMES-project)

## 三、用什么图，怎样拆更准更快

| 资料 | 正确用途 | KANPACE 下一步 |
|---|---|---|
| 客户效果图 / 3ds Max 场景 | 理解外观、空间和客户认可的样子 | 留作整体参照；设计端导出真实 GLB 才可旋转查看 |
| 已发布施工图 / 深化图 / 零件加工图 | 识别对象、材料、数量、尺寸、孔槽和验收要求 | 原图定位、OCR 辅助、字段核对、缺项追问 |
| SolidWorks 原生装配、零件、工程图和 BOM | 工程设计主档及正式制造信息 | 收齐引用文件、配置与版本；设计端导出发布 BOM、图纸和 STEP |
| STEP | 核对实体几何、结构和实例 | 辅助查错；不直接把包围尺寸当下料尺寸 |
| GLB / OBJ / STL | 浏览已导出外观或几何网格 | 可旋转、选择；不凭节点数确定订单数量 |
| 服装纸样、印刷刀模、PCB 资料、配方工艺卡 | 各行业的专用技术输入 | 按行业接入，不能统一改成 SolidWorks 图纸 |

网页使用派生模型是合理方式，关键是它必须由真实设计导出，并能回到原件版本。3ds Max 2026 官方支持 GLB 导出，但存在层级展平及材质等限制；这不是完整原生场景编辑。[Autodesk GLB 导出说明](https://help.autodesk.com/cloudhelp/2026/CHS/3DSMax-Interoperability/files/GUID-5B4C8EC2-2230-4F9F-B3C6-48D9E347E37D.htm) SolidWorks 装配应收齐引用文件，可用 Pack and Go 组织原件；只收一个 SLDASM 不能证明依赖齐全。[SOLIDWORKS Pack and Go](https://help.solidworks.com/2024/english/SolidWorks/sldworks/c_pack_and_go.htm)

准确和速度同时改进的顺序：优先复用已有加工单/BOM；按图号和版本确定对应对象；只对未结构化区域做 OCR；让人只核对冲突、缺失和关键制造字段；生成任务前检查来源、单位、数量和制造要求；任务引用固定发布版，变更只影响相关对象。这比对每张效果图重新猜模型更接近真实节省。

## 四、中台最先补的六个能力

1. **对象与路线匹配。** 同单木件、铁件、玻璃分别走路线；机械的机架和电柜也不同。目前企业工作包存在“每对象复制全部节点”的限制，需要替换成按对象类型选择路线。
2. **跨对象齐套。** 以柜号、设备部套、安装区域或款色码汇合。不能因一个柜缺玻璃，就挡住所有其他柜；也不能只看工种完成百分比。
3. **批次拆合及数量。** 多卷入缸、多批拼茶、一批分装、母卷分切都需要投入—处理—产出关系。合格、待检、返工、报废分开；单位与换算必须明确。
4. **人、设备、工艺等待分开计时。** 工人暂停换单可释放人员；窑炉烧成、涂层固化、茶焙火和晾香不会因此暂停。不把自然等待全部计为人工工时。
5. **资料角色和来源链。** 原生主档、整体效果、加工依据、派生模型、批准样分开，绑定来源与版本。项目主模型由人指定，不能用最后上传的零件冒充整体。
6. **可预览、可安装的工厂方案。** 行业通用包 + 本厂对象/工种/资源/字段映射 + 一单预演 + 主管确认 + 独立工厂安装回执。通用模板没有客户图纸、配方、价格或实际产能。

目前已有独立本地工厂实例、流程模板版本、工作包复核、任务执行、Excel预览导入及排程等基础；还没有完整的“上传资料就配置整厂”闭环。现有本地隔离也不等于云端多租户已验收。完整审计见《20260907-工厂配置中台审计.md》。

## 五、排产时间要怎样估，才不误导老板

单节点拆开记录准备/换型时间、人工投入、设备占用、工艺等待、外协运输和质检等待。人工时长、机器时间和交期时间分别展示。

首单先取本厂工艺员估计范围并注明依据；随后采集开始、暂停、恢复、合格产出与等待原因，用同产品族、数量、工位的可比实绩校准。没有实绩或工艺卡时显示“待估时”，不从企业规模或模型体积凭空给出分钟数。

没有资源冲突时，串行段累加、并行段由最晚满足条件的分支决定下步；实际还要检查共享人员/设备、批容量、齐套、检验、日历和外协到货。窑炉、染缸、连续纸机需要自己的容量模型。插单先看受影响订单与在制状态，不能因为优先级高就打断不可中断的工艺。

## 六、第一次见老板，收六包资料

| 要收的资料 | 用来回答什么 | 首次不必提供什么 |
|---|---|---|
| 一张代表性订单和原 Excel | 产品、数量、交期、客户编号 | 全年所有订单 |
| 这一单批准技术资料 | 图纸/样品/配方谁说了算，版本怎样区分 | 无关项目资产 |
| 实际流程与排程表 | 哪些自己做、哪些外协、哪里汇合 | 重新为软件画一套理想流程 |
| 班组、工位、设备和工作时间 | 谁会做、哪里做、什么资源最紧 | 初期复杂人事档案 |
| 当前库存/缺料与供应交接记录 | 到货怎样转为可用，外协怎样回厂 | 全套财务总账 |
| 一单完工/质检记录和一次异常 | 怎样算合格、怎样暂停换单、怎样验收收益 | 没有记录时猜准确工时 |

生成顺序：识别本厂职责 → 对应字段与对象 → 生成可核对路线、任务卡和缺项 → 老板/工艺负责人确认 → 安装本厂方案 → 用一单比对原表 → 正式启用。客户只看自己的资料和结果；本厂修改留在本厂，共用库仅沉淀经过授权的一般流程定义。

## 七、商业价值与试点顺序

优先顺序是产品判断，不是实测市场排名：

- 第一批：现有展柜样板 + 安溪藤铁木作 + 南安工程石材 + 专用机械小装配。共性是资料复杂、多工种、外协与齐套，最接近已有能力。
- 第二批：选一个成鞋/成衣款色码样板、一个纸盒版次样板，或卫浴配套/德化人工工序样板。每次验证一种新对象，避免同时铺开。
- 后续：食品茶、染整、香等补好批次和质量放行；建陶纸机等对接连续产线；石化、半导体先做外围检维修协同，核心控制与专用MES单独评估。

当地数字化试点曾明确聚焦休闲体育用品、食品加工、工程机械与纺织专用设备，可作为访谈与生态合作的线索；本报告不据旧申报通知承诺当前补贴资格或金额。[泉州市工信局，2025-04-08](https://gxj.quanzhou.gov.cn/zwgk/tzgg/202504/t20250408_3156490.htm)

建议每个样板先记录旧流程基线，再做同类订单对照：交底包准备时间；工人找图/问图次数；错版返工；缺件等待；一次合格产出；按承诺日期交付数量。追踪中位数和长尾，不把一个最快订单当平均值。

月度可核验收益可按“节省交底/追单人工 + 减少返工直接成本 + 减少有记录的加班/加急损失 − 新增运行和实施成本”核算。同一损失不重复计入，节省工时不自动等于现金节省。图谱列出的指标均为建议采集项，没有填虚构改善百分比。

真正可积累的壁垒是：来源到对象的可靠对应、经工艺验证的路线和例外、对象/批次交接、可解释的时间预测、无需工人反复填表的回执。开源内核提供基础能力，企业图纸和配方不能为了积累模型而跨客户混用。

## 八、页面与硬件收敛方向

日常入口建议围绕四件事组织：今天要办、项目与资料、排产与派工、经营情况。各组展开直接看到常用小标题，保留快速抵达；工牌连接和工厂配置作为固定辅助入口。Agent 接受“找出这单缺件”“安排已齐套的柜子”等动作，先定位对象、调用实际能力，必要时给差异预览。不能只靠聊天入口把常用功能藏得更深。

硬件共用一张当前任务卡，根据岗位换内容：木工看板件局部图，装配看部套，检验看标准样与判定，搬运看批次和位置。连续产线优先固定工位屏或自动计数；不能把“每人一块小屏”当成所有行业的答案。

## 九、本轮实际修改与未完成项

已把当前模型查看入口统一为“工程模型”，增加折叠的SolidWorks/3ds Max资料准备说明；旧推演页面改名“清单尺寸示意”，直接说明没有读取原设计模型；修正能力说明中对已存在排程/矩形套料的过时描述。本轮不改变导入器支持格式，也没有让MAX或原生SolidWorks变得可以直接解析。

项目主模型的显式指定、原件和派生文件关系、按对象路线/跨对象汇合、批次拆合、完整工厂方案安装仍是待实现项。可切换行业图谱是调研成果，不是已启用的19套工厂配置。既有生产数据不因这次调研或文案修正发生变更。

# 泉州产业业务链：装备、石材、卫浴、电子

核验日期：2026-09-07。用途：为 KANPACE 的行业选择、工厂初始化和流程配置提供依据，不是企业现场实施方案。已阅读用户提供的《泉州产业调研2607_V2.html》，其中企业与产业分类作为检索线索；以下事实独立核验于企业披露、企业官网和政府网站。未使用集群产值估算市场容量，未联系企业、读取企业内部系统或上传客户文件。

**产品判断：适合复用的是“工程版本—物料—工序—人员/设备—质量—交付”的数据骨架，不能复用一条固定展柜生产线。** 以下“建议业务链”“输入资料”“配置对象”均为行业通用建模推演，需用目标工厂的一张真实订单、工艺卡和完工记录确认；不是声称列名企业逐项使用这些文件或工序。公开报道有既有 PLM/MES 时，优先从其已发布数据接任务、回传进度，不能另造相冲突的主档。

## 1. 机械装备：以单台设备和部套齐套为中心

**直接证据。** 铁拓机械2025年ESG报告第19–20页披露：其PLM管理设计资料，图纸按工序、班组存储并动态送到车间终端；三维模型和工艺参数服务切割、焊接、装配、质检，车间图纸异常可反馈设计。证明“资料与岗位任务关联”是当地真实需求，也表明成熟工厂可能已经有PLM。[铁拓机械2025年ESG报告](https://static.cninfo.com.cn/finalpage/2026-04-14/1225102146.PDF)

**建议输入。** 客户技术协议/订单配置、发布的装配BOM和零件图、SLDASM/SLDPRT完整引用包、STEP派生模型、焊接/加工图PDF或DWG/DXF、电气原理图/接线表、采购清单、检验规范。STEP几何不能代替材料、焊缝、配合、公差和采购件型号；效果图只解释整体样子。

**建议业务链。** 技术确认→发布部套BOM后分支：①结构件备料→切割/成形→组焊→加工/表面处理；②机加工件毛坯→加工→检验；③电机/轴承/气液压等采购件→到货检验；④电柜/线束备料→装配接线。按部套齐套汇合→机械/电气总装→调试→验收→分件包装/运输→现场安装交付。热处理、精加工、喷涂等可按本厂能力设为外协节点，不能默认所有企业都外协或固定同一加工先后。

**关键对象。** 设备项目号、设备序列号、部套/零件号及版本、单件/批次数量、采购到货、工序检验、外协发出与回厂、设计变更影响范围。并行分支按部套和需求数量汇合；不能只检查“几个工种都点了完成”。

**KANPACE切入。** 工程资料发布后，自动核对BOM/图号对应，形成工种图文包；把缺件、外协延期、返工和装配条件呈现给主管；保留PLM/ERP编号及版本。先覆盖部套交接、装配齐套和现场反馈。不承诺由任意STEP自动还原原生参数树、焊接工艺或完整制造BOM。

## 2. 石材加工与石雕：至少拆成两种模板

## 结论与证据边界

**先选择工厂的生产对象，再生成资料、工序、人员和交接界面。** 同属“泉州制造”，鞋服按款色码和裁片包推进，染整按卷布和染缸推进，食品茶按配方批次推进，纸品按卷材和机台连续生产，包装按印件版次和批量推进。把这些都变成“图纸识别出零件，再给每个零件套相同工序”，会产生错误的任务数量、数量单位和依赖关系。

用户提供的《泉州产业调研2607_V2.html》用于确定产业范围和企业线索。其中产业规模、企业收入、份额有不同年份和统计口径，本次不据此作排名或投资判断。以下“已核实”来自政府公开文件、企业年报；“模板建议”是根据这些证据提出的典型流程推演，**不是对某家工厂现行 SOP 的完整还原**。环评描述拟建/技改工艺，不能单凭环评认定产线已经投运。来源访问日期均为 2026-09-07。

KANPACE 的共用层可以保留订单、附件版本、工艺节点、班组/机台、开工条件、异常暂停、外协交接、质量放行和交期看板。行业差别必须进入对象、数量、依赖和质量字段，不能只更换左上角名称。

## 1. 鞋业：以款色码和配双齐套为主

**已核实。** 晋江公开的灌篮高手（中国）高分子科技有限公司项目环评，将运动鞋生产分为鞋面加工、鞋底加工及复合；鞋面涉及材料裁切与拼缝，鞋底有处理、上胶等环节，随后压合、冷成型、包装。报告另列 TPE 颗粒生产，说明鞋材厂与成鞋厂本身就是不同路线。来源：[晋江市政府公开环评，编制于 2025-03，公开路径日期 2025-04-03，PDF 第 33–34 页附近](https://www.jinjiang.gov.cn/xxgk/zdxxgk/hjbh/jsxmyxpj/202504/P020250403436236946521.pdf)。

**模板建议。**

- 输入：订单款号与颜色尺码矩阵、确认样鞋照片、鞋面版型/裁片文件、材料 BOM、楦型/底模版本、工艺单和交期。外观图帮助认款，材料规格和技术单决定制造。
- 主路线：样品/工艺确认 → 鞋面裁片与针车；与此同时鞋底、鞋垫及辅件准备 → 按同款同色同码齐套 → 成型装配 → 检验配双 → 装盒装箱。底材自制厂另选注塑/发泡/硫化等专用路线，不能默认成鞋厂都有。
- 并行与外协：鞋面与鞋底两支在成型汇合；印花、绣花、底材或模具可按工厂实际外协。外发时记录数量、款色码、技术版次、回厂日期和验收；少一部分尺码不能用总数量“已齐套”掩盖。
- 任务对象与质量：裁片包、帮面包、成型批；单位为片/双/箱且有换算。重点是左/右配对、尺码缺口、色差、材料批号、胶合/外观检验及返修原因。
- KANPACE 切入：成型齐套看板、针车与外协交期、断码预警、工人屏显示样鞋局部和本工序位置。不要把“一双鞋”膨胀成大量工牌单任务，也不要从渲染图猜胶水、楦型或工艺参数。

## 2. 纺织与染整：以卷布、染批和机台容量为主

**已核实。** 泉州市工信局对凤竹高档化纤面料技改项目的节能审查，列出纱线/化纤针织布以及织造、染色、定型、拉毛等工艺。它支持“织造—染整”路线族，不能代表所有棉、锦纶、涤纶面料具有相同工序。来源：[泉州市工信局，凤竹技改项目节能审查意见，2024-11-07](https://gxj.quanzhou.gov.cn/zwgk/tzgg/202411/t20241107_3102454.htm)。

**模板建议。**

- 输入：面料订单、成分/组织/幅宽/克重、颜色及确认色样、坯布卷号与重量、加工工艺卡、检验要求；来料加工厂主要接收坯布和加工要求，不必生成织造任务。
- 主路线：纱线准备 → 织造 → 坯检；或从来坯验收开始 → 按工艺分组与配缸 → 前处理/染色 → 脱水与干燥/定型 → 按需后整理 → 成品检验 → 分卷包装。具体顺序和返染路线由厂内工艺人员确认。
- 并行与汇合：色样确认可与来料准备并行；通过确认后才允许大货投缸。多卷可合成同一染批，出缸后再拆为多个成品卷；这是真实的多进多出关系，不是简单的对象内部前后工序。
- 任务对象与质量：纱批、坯布卷、染缸批、成品卷；kg/m/卷分别记量，换算保留幅宽和克重依据。色批、缸号、实测色差、缩水/手感/克重等检测结果需要关联实物批次。
- 外协与排程：织造、染整、印花、后整理可跨厂。排程需机台可加工范围、最小/最大装载、清洗换色和等待时间；不能只以“人数 × 每件工时”排染缸。
- KANPACE 切入：委外在途、待确认色样、待投缸齐料、返染异常和质检放行。先做批次协同，再接成熟染整控制系统；不由 AGENT 自行生成染料配方与设备设定。

## 3. 成衣：以款色码订单和裁片包流转为主

**已核实。** 石狮政府对缝制设备的介绍明确区分缝前 CAD/CAM、拉布裁剪、缝制与缝后整烫、吊挂仓储；另一篇报道描述当地服饰企业采用智能吊挂生产针织运动服、梭织运动裤。来源：[石狮市政府，海博会智能智造馆，2024-04-15](https://www.shishi.gov.cn/zwgk/xwzx/jrss/202404/t20240415_3026705.htm)；[石狮市政府，智能制造升级生产链，2025-05-29](https://www.shishi.gov.cn/zwgk/xwzx/jrss/202505/t20250529_3174647.htm)。

**模板建议。**

- 输入：款式技术包、样衣/局部做法照片、尺寸表与公差、纸样及排料文件、面辅料 BOM、颜色尺码数量、包装配比。服装纸样 CAD 是专业二维版型，不能按 SolidWorks 装配 BOM 处理。
- 主路线：样衣/纸样确认 → 验布与排料拉布 → 裁剪分包 → 按需印花/绣花 → 缝制 → 整烫 → 检验 → 按尺码配箱。领、袖、前后片可按工艺分别加工，再汇合；并非所有款式均采用同一节点。
- 外协：印绣花、洗水、缝制加工按工艺选择；必须关联裁片包及面料色批，回厂缺片、损耗或色差不能仅以订单完成百分比表达。
- 任务对象与质量：款色码 → 裁床/铺层批 → 裁片包 → 衣件/箱；缝制缺陷类型、尺寸实测、返修次数、合格数量与不良数量分别记录。
- KANPACE 切入：裁片与辅料齐套、外协交接、工序停滞和返修闭环，工人屏显示当前缝制部位、合格样例和需完成包数；已使用吊挂系统的客户优先交换工单与完成记录，不再让工人重复逐件报工。

## 4. 食品与饮料：按产品路线区分，核心是配方批次与放行

**已核实。** 安记食品 2024 年报披露：月度销售计划结合库存形成生产计划，车间按计划生产，质量检验合格后入库；其粉类调味品设备涉及投料、配比、混合、干燥、包装。来源：[安记食品 2024 年年度报告，披露于 2025-04-22，第 12–13 页](https://static.cninfo.com.cn/finalpage/2025-04-22/1223193223.PDF)。饮料不可据此套用粉体路线：惠安 2026 年达利技改审批公示分别列有蛋白饮料、功能饮料、茶饮料、罐头饮料等产品。来源：[惠安县政府，达利技改项目拟审批公示，2026-05-19](https://www.huian.gov.cn/zwgk/zdxxgk/hjbh/sydbh_46348/202605/t20260519_3293032.htm)。

**模板建议。**

- 输入：生产计划/SKU、受控配方与工艺卡、原辅料和包材清单、原料批次/有效期、包装标签版次、厂内质量检验与放行要求。销售效果图不是制造依据。
- 路线族：粉体调味料选配料—混合—按需干燥—包装；烘焙品选备料—成型—烘焙—冷却—包装；饮料选调配—经确认的处理/灌装工艺—封装—检验。这里是建模分组，不是可直接下机执行的配方或工艺参数。
- 并行与汇合：原料称量、包装材料准备、设备清场/清洗确认可独立推进；生产启动要共同满足放行条件。散装批可分为多包装批，多原料批可共同进入一成品批，需记录真实投料关系。
- 外协：原料预处理、委托加工、检验及包材供应分别管理；外协“到货”与“检验可用”应是两个状态。
- 任务对象与质量：配料批、生产批、包装批、托盘；实际投料量、产出量、损耗和返工去向，以及过敏原/清场、待检/合格/隔离状态。保质期、检验项及阈值由客户受控规则提供。
- KANPACE 切入：班组准备、缺料、换线、异常上报、待检和交班。进入完整食品生产执行前，必须补齐批次谱系、多进多出数量守恒与质量放行权限；现有普通任务完成按钮不能代替食品放行，也不能声称已具备完整追溯召回能力。

## 5. 安溪茶：初制与精制两种工厂，批次会拆分与拼配

**已核实。** 泉州市政府对安溪铁观音制作技艺的介绍，区分采摘、初制和精制：初制包含做青、炒青、揉捻与多轮烘揉；精制有筛分、拣剔、拼堆、烘焙、摊凉和包装。该来源强调依据鲜叶与天气调整制作。它描述铁观音工艺，不能扩展成所有茶类的固定 SOP。来源：[泉州市政府，安溪乌龙茶（铁观音）制作技艺，2015-10-29](https://www.quanzhou.gov.cn/lyb/mfms/mjgy/201510/t20151029_181701.htm)。

**模板建议。**

- 初制输入鲜叶来源、采摘日期、品种、重量和验收结果；精制/品牌加工输入毛茶批次、等级与评审记录、拼配要求、包装规格。单纯茶叶销售门店只需要入库、分装及追溯，不应生成初制车间。
- 初制模板按鲜叶批生成做青/加工/干燥任务；精制模板按毛茶批生成筛拣、按需拼配/焙火、冷却、评审、包装。部分烘揉环节重复，宜记录同一加工批的轮次，不能为了画成单向流程而抹掉轮次。
- 并行与汇合：不同毛茶批可分别整理后拼配；筛选又可分为不同等级。包材准备与加工可并行，成品评审通过再包装放行；外购毛茶、委外焙火/分装需要批次交接。
- 任务对象与质量：茶批、分级子批、拼配批和包装批，主要单位 kg；记录来源与季节、加工/拼配版次、感官评审和实测结果，不能只记“做完一件”。
- KANPACE 切入：师傅待办、加工轮次、批次交接、样品评审及包装防混批；工牌显示批次、重量、下一步与待确认事项。时间先取工厂历史记录范围，由师傅确认；不从效果图推算制茶条件，也不把传统工艺说明当作最新产品执行标准。

## 6. 生活用纸与卫生用品：至少拆成原纸、后加工、卫生用品三类

**已核实。** 恒安纸业项目环评分别给出湿法吸水纸和吸水衬纸工艺：浆板处理后抄造、烘干、卷取等；湿法吸水纸还涉及吸水树脂及复合。该证据描述原纸/吸水纸，不能直接当作纸尿裤整线。来源：[泉州市生态环境局，恒安纸业项目环评，公开路径日期 2024-10-31，PDF 第 61–63 页](https://sthjj.quanzhou.gov.cn/hjgl/hbsp/hpslqkgk/202410/P020241031581421442138.pdf)。洛江区产业报道另列流延膜、无纺布和卫生用品机械等上游，以及卫生巾、婴儿纸尿裤等中游产品，支持区分材料厂与成品厂。来源：[泉州市政府，洛江卫生护理用品产业链报道，2026-04-07](https://www.quanzhou.gov.cn/zfb/xxgk/zfxxgkzl/qzdt/qzyw/202604/t20260407_3281183.htm)。

**模板建议。**

- 原纸厂：输入浆料/助剂工艺卡和规格 → 备浆/抄造/干燥/卷取 → 检验；后加工厂：从外购大轴纸验收开始 → 按 SKU 选择复卷、压花、折叠、分切 → 包装。不要把造纸任务分给只做纸巾分切包装的客户。
- 卫生用品厂：输入 SKU、层材与芯体结构、原材料卷号、工艺/换型卡 → 芯体及多层材料准备 → 复合成型 → 在线检测与剔除 → 包装。此为典型建模建议，需用客户设备和工艺卡确认实际顺序。
- 并行与汇合：材料卷、芯体物料、包材及产线换型分别准备，开线时汇合；一个原料卷会消耗在多个成品批，一次换卷也可能出现在同一生产批中。外购大轴纸/薄膜/无纺布与委外分切要有卷号级交接。
- 任务对象与质量：原纸卷、子卷、机台生产批、成品包装批；kg/m/卷/片/包的换算受规格和实际消耗约束。重点是幅宽、克重/层数、吸收或外观检测、废品量、换卷时间、停机原因和清场记录。
- KANPACE 切入：换型准备、首件确认、巡检异常、停机维修及班组交接。连续高速产线优先从设备或既有系统获取数量，不要求工人逐片点击工牌；现有展柜开料优化也不能直接冒充卷材连续生产控制。

## 7. 包装印刷：以签样版次、印件批和机台为主

**已核实。** 晋江公开的大邦包装项目环评描述外购纸张裁切、印刷、裱背、复膜、上光、分切压痕、糊盒成型，并明确印版外协加工。来源：[晋江市政府，大邦包装盒生产项目环评，编制于 2023-01，公开路径日期 2023-03-29，PDF 第 21–22 页](https://www.jinjiang.gov.cn/xxgk/zdxxgk/hjbh/jsxmyxpj/202303/P020230329585161203819.pdf)。该案例针对纸盒，软包装凹印复合、瓦楞纸板制造、食品纸袋还需独立路线。

**模板建议。**

- 输入：客户签字确认的设计稿与颜色样、刀模/展开图、纸材/克重/楞型、工艺组合、数量和包装方式。主图应是已签样成品或展开稿；结构 CAD、印前文件和签样版次共同作为工程依据。
- 主路线：稿件/结构审核 → 排版与制版准备 → 印刷 → 按需裱合/覆膜/上光等表面处理 → 模切压痕 → 糊盒/成型 → 检验包装。不同工艺组合生成不同节点，不把所有表面处理强制串联。
- 并行与外协：纸料、印版、刀模可并行准备，在对应印刷/模切节点汇合；外协制版、烫金或覆膜按厂内能力配置。任何印版/刀模回厂要核对订单版次，不能只确认“已收到”。
- 任务对象与质量：印件版次、印刷批、托纸批和箱；良品/开机损纸/报废分别计量，签样色、套印、条码、模切和糊口检验关联本批。
- KANPACE 切入：签样冻结、版材齐套、工序交接与异常停机，工牌显示当前印件、版次、局部质量示意和待加工数量。读取刀模几何有价值，但不能由效果图推导色彩参数；展柜矩形板材排料不等于专业印前拼版或不规则刀模套排。

## 中台应该增加的最小配置，不扩成一套大 ERP

以下为产品设计建议，与同目录《20260907-工厂配置中台审计.md》的现有实现边界配合使用。

| 配置项 | 必须回答的问题 | 对生成平台的实际影响 |
| --- | --- | --- |
| 工厂生产环节 | 成鞋还是鞋底？染整加工还是织染一体？原纸还是后加工？ | 只生成实际承担的路线，外部环节成为收货/委外接口 |
| 生产对象与单位 | 款色码、裁片包、卷、缸、配方批还是版次？ | 决定任务颗粒度、数量字段、识别码和列表列项 |
| 输入资料包 | Excel 哪些列？批准样品/配方/版型/图纸分别是谁？ | 建立带版本的来源映射，缺信息先列待确认，不凭图补造 |
| 条件路线 | 什么产品或工艺组合才走这个节点？ | 不再对象乘全部工序；不同对象选择不同节点集合 |
| 依赖与齐套 | 本对象前序、其他对象齐套、质量放行还是物料可用？ | 支持鞋面鞋底汇合、印版到位和食品待检等真实阻塞 |
| 拆分/合并 | 多卷入缸、拼茶、多批投料、原纸分卷如何追踪？ | 需要输入批—处理事件—输出批关系及实耗，不能用任务依赖冒充 |
| 资源与时间依据 | 人工件时、机台批时、换型时间还是等待/冷却时间？ | 分别记录加工、准备、等待及来源；人工确认估计与实测反馈分开 |
| 工人显示与报工 | 哪张批准图、哪个局部、何种单位；手工还是设备回传？ | 保留任务/图片/异常与操作，连续线不堆逐件待办 |
| 质量与外协 | 哪个节点禁止未放行流转？外发/回厂谁验收？ | 完成、到货、检验合格分别记状态，保留责任人和证据 |

**落地顺序建议：**先把款色码离散任务、纸盒版次任务做成可预览的行业模板，用一张客户真实 Excel 和一单历史订单进行比对；批次行业先交付“计划—准备—异常—交接—放行”的协同层。补齐批次谱系、单位与数量约束后，再扩大到配料和生产追溯。任何模板都经过“草稿 → 一单预演 → 工艺人员审核 → 固定版本 → 安装到工厂实例”，在制任务不因模板升级自动改写。

**一次工厂开通应收集的最小资料：**一份典型订单及 Excel、一套批准技术资料、一张真实流转/排程表、班组机台及外协清单、一次缺料/返工案例、一份质检放行记录。上线验收看四件事：任务是否落到正确对象与责任人、下道工序是否被正确条件挡住、工人是否能看懂本次工作、完成及异常是否回到原有表格。不要以页面菜单数量作为适配完成的标准。


# 泉州产业链路：工艺与流程制造对 KANPACE 的适配

调研日期：2026-09-07。范围：德化日用/工艺陶瓷、晋江建筑陶瓷、安溪藤铁与木作家居、永春香、泉州石油化工。依据用户提供的《泉州产业调研2607_V2.html》选定地域与行业，再核对政府、企业公开披露和项目文件。本文没有联系企业，也未接触企业内部工艺或控制系统。

**建议先复制安溪藤铁/木作，其次选择德化的人工成型、修坯、装饰和装窑交接。建陶、香需要先补批次管理；石化只宜先研究检维修和交接等协同环节。** 这是根据现有 KANPACE 能力提出的产品适配排序，不是当地市场规模或企业采购意向排名。

## 证据口径

## 1. 德化日用陶瓷与工艺陶瓷

**公开事实。** 德化县政府 2026 年工作报告把大师艺术瓷、日用家居瓷、出口工艺瓷列为不同发展层次。德化恒忆的历史公开转让说明书分别列出艺术陶瓷、手捏瓷和日用陶瓷路线，其共同环节包括制坯、干燥、施釉、装窑、烧成、选瓷；手捏艺术瓷有额外的手工造型和装饰过程。不能把三类产品套成同一道流水线。[政府工作报告，2026-03-05](https://www.dehua.gov.cn/zwgk/ghjh/zfgzbg/202603/t20260305_3271814.htm)、[恒忆公开转让说明书，2016-07-27 披露路径](https://static.cninfo.com.cn/finalpage/2016-07-27/1202520103.PDF)

**建议流程。** 客户设计/样品确认→模型与模具批准→按本厂配方备泥/备釉→成型→适用的接坯、修坯、装饰与干燥→选坯/施釉→装窑→烧成与冷却→选瓷/必要返工→配套包装。日用器型偏向模具和批量一致性；工艺瓷需要雕塑版本、手工修整样例和外观认可，不能仅按标准零件数量衡量进度。

**必须向工厂收的输入。** 订单与 SKU、批准样品照片/造型模型、模具号与版本、泥釉配方的受控编号、坯体与成品规格、成型方式、装饰要求、窑炉可用计划、烧成曲线版本、验收和包装配套表。生产参数来自厂方，照片或 STL 外形不能直接推出缩水补偿、壁厚或配方。

**需要的新约束。**

| 对象 | 产品模型应怎样表示 |
|---|---|
| 泥料/釉料批次 | 成品批次可追溯到原料批次和配方版本；共享一批泥料不等于共享一个订单 |
| 模具 | 型号、可用套数、状态、适用产品；模具不足形成成型能力约束 |
| 坯体流转 | 合格数、待修数、破损数、报废数分别记录；不能把所有上道投入数当下道可用数 |
| 窑次/窑车 | 一窑可以关联多个订单批次，容量与烧成条件兼容性由窑工确认；不是简单“哪个任务最急就插进去” |
| 人与窑炉 | 装窑、卸窑是人工任务；烧成和冷却属于设备/工艺状态。人员下班不能自动把窑次暂停或累计整段为人工工时 |
| 外协 | 模具、白坯、贴花或烧成是否外协逐厂登记，保留发出批量、预计回厂、实收和验收，不假定所有工厂自制全部环节 |

**KANPACE 第一单切入。** 选一个打样或小批订单，把批准样品、修坯局部图、装饰要求和包装配套分成图文交底；用托盘/批次卡记录从成型到入窑的数量交接。先解决拿错样、遗漏装饰、错混批次和找不到半成品，不承诺自动设定烧成曲线。

**工牌适配。** 修坯/装饰/检选工位适合显示样品图、批号、目标数量、关键外观和交接。热区、潮湿、泥尘和戴手套操作要单独验证；窑口看板可能比胸前小屏更适合整窑作业。工牌只负责任务与确认，不直接控制窑炉。

## 2. 晋江建筑陶瓷

**公开事实。** 晋江产业链方案明确原材料加工、坯土、色釉料、机械模具和物料配送的配套，并提到球磨、窑炉余热、自动填装及分拣包装。政府公开的一个建陶改建项目摘录列出矿料/釉料球磨、喷雾干燥、压砖、施釉、辊道窑及烘干窑；这是该项目的设备路线证据，不代表所有砖瓦厂的工艺配置。[晋江产业链行动方案，2025-01-15 公开](https://www.jinjiang.gov.cn/xxgk/zfxxgkzl/ml/03/202501/t20250115_3131015.htm)、[建陶改建项目环评附件，2021-08 路径，正文抓取超时](https://www.jinjiang.gov.cn/xxgk/zdxxgk/hjbh/jsxmyxpj/202108/P020210802638224520415.pdf)

**建议流程。** 订单/花色规格→批准产品配方与工艺→原料及釉料制备→适用的制粉与储料→压制/成型→干燥→施釉与装饰→烧成→适用的后加工→分级检选→按色号、尺码与批次包装入库→配货。烧成后加工有无抛光、磨边等，要由产品路线决定；不能把墙砖、地砖、瓦都套同一模板。

**输入。** 产品规格和样板、花色/版面版本、配方和料仓批次、模具、产线/窑炉适用范围、生产与换型计划、验收规则、包装片数与面积换算、库存批次及订单配货条件。

**约束推演。** 建陶应以“产品批次＋产线时段”排产，人工任务只是换型、检验、交接、维修等部分。需要识别连续产线、缓冲库存、模具/釉色切换、共用制粉与窑炉能力，不能用现有“一个人一次只执行一个任务”推导整个生产线吞吐量。色号、尺码和等级需追踪至托盘/箱批；片、箱、平方米、吨按经批准换算，不允许直接相加。

**第一单切入。** 先接现有排程 Excel，围绕一条线做换型准备、首件确认、缺陷处置、分级入库与班次交接，老板查看“本批能交多少、哪部分待判定”。正式替代产线 MES 前，批次拆合、产量报废和连续设备能力是必补项。

**工牌适配。** 更适合首件检验、巡检、维修和交接人员；高速流水作业优先考虑固定工位屏或批次标签。现 ESP32 原型并未证明适用于热、尘、水雾环境，也不是在线仪表或窑炉控制器。

## 3. 安溪藤铁、木作与多材料家居

**公开事实。** 泉州市生态环境局的藤铁行业技术规程明确存在切割、焊接、抛丸、喷粉、喷漆及固化等环节，并指出企业间工艺、设备与原料不同。安溪地方政府人员在中国工艺美术学会发布的演讲介绍了竹藤技艺与金属工艺融合的产业特征。二者支持按多材料、多工种理解该行业，不支持为所有产品强制安排同一套表面处理。[藤铁行业技术规程，2020-09 文件路径](https://sthjj.quanzhou.gov.cn/xxgk/zfxxgkzl/zfxxgkml/hjxx/202009/P020200928632725052979.pdf)、[安溪家居工艺产业主旨演讲，2023-01 发布](https://m.cnacs.net.cn/125/202301/4537.html)

**建议流程。** 客户图片/样品与尺寸确认→结构拆件及打样→批准样→金属骨架加工、木件加工、藤/竹备料并行→按产品做法处理表面→编织/组合装配→外观和功能检验→配件齐套→包装装箱。编织与涂装谁先谁后必须依材质、连接和色彩要求确认；木材烘干、机加工、打磨/涂装等步骤只在本厂实际存在时加入。

**输入。** 客户批准样、结构图/尺寸表、部件与材料清单、色板/纹样、编织方法样例、焊接或连接要求、零件数量、外协清单、包装箱唛/装柜要求。图片只有审美意图时先派打样或技术确认，不能从产品照片算精确下料。

**约束推演。** 可复用展柜的木工、五金、表面处理、装配与质量门槛，但要增加编织技能、样板审批和多地点外协批量交接。按产品编号汇合；金属件、木件、藤件分别缺料，不让一个外协批延误所有已齐套产品。涂装可以由工艺人员确认按同色批处理，但不能自动混入验收要求不同的订单。

**第一单切入。** 一个花架、收纳或家居产品从批准样到部件图文交底，再到外协收发和装配齐套。这是当前 KANPACE 距离最短的复制场景：现有项目、工种、局部图、负责人、暂停/交接和分批发货大部分可以沿用。

**工牌适配。** 展示批准样、局部结构、编织纹样、颜色、数量及交接位置。手工岗位看得懂图是重点；工件加工旁是否佩戴、手套触控与粉尘/涂装环境要试用确认。工人暂停换做其他单可沿用现有闭环，已进入涂装/固化的工艺状态仍要单独记录。

## 4. 永春香

**公开事实。** 永春县政府资料列出篾香、线香等不同品类，不能把全部香品视为带竹芯的一种产品。泉州市科技局 2026-06-26 的工作信息直接提出改进原料配比、自动化制香设备和晾香流程，关注易霉变、粗糙等问题，并列出检测与研发服务。产品品类、配方、干燥与质量是管理重点，不仅是包装件数。[永春概况，页面未单列更新日，2026-09-07 查阅](https://fjyc.gov.cn/zjyc/ycgk/)、[泉州市科技局：全链条赋能，2026-06-26](https://kj.quanzhou.gov.cn/xxgk/kjxw/202606/t20260626_3303903.htm)

**建议流程，待企业核定。** 接单/香型样品批准→确认配方版本与原料→粉料准备及配料/混合→按篾香、线香等选择成型路线→按做法整理/着色→晾晒或厂方实际采用的干燥→检验与留样→分装/礼盒配套→成品批号与出库。当前官方资料可证明配方、设备和晾香的重要性，未取得一家具体香厂覆盖所有环节的完整 SOP，故这里不称为该厂实况。

**输入。** SKU 与香型样品、配方编号/批准人、原料批次和供应商、称量要求、成型规格、晒架/干燥批次、放行条件、包装与标签版本。完整配方只给授权岗位；其他工人只看自己的投料卡或操作要求。

**约束推演。** 一个原料批次可能用于多个生产批，一个成型批又可能拆到多个晒架；成品包装可与生产批不同，需保持关联。干燥受本厂方式和实际条件影响，不能给所有香统一固定时长。含水、断裂、外观及适用检验应由厂方确定放行标准；“晒够几个小时”不能自动代表合格。重量、支数、把数、盒数换算要有依据，损耗和不合格分别记录。

**第一单切入。** 选一个香品类型，先把配方版本确认、备料、晒架位置、待干/待检/可包装状态和礼盒缺件串起来；收集批次完成与异常。暂不做自动配方优化，也不把系统推荐描述成养生或健康功效。

**工牌适配。** 优先给晾晒、搬运、检验、包装人员显示批号、位置、数量及下一动作；配料岗位使用经批准的单步卡。粉料、清洁、潮湿与户外光照下的使用需实测，配方不应默认广播到所有工牌。工人暂停可以释放人员，正在晾晒的批次应继续处于“等待干燥”而不是停表。

## 5. 泉州石油化工

**公开事实。** 中国中化官网说明泉州基地以炼化一体化原料延伸到下游材料；2025-04-30 公布的丙烯腈项目包含 AN、MMA、废酸再生及公辅工程，明确记录投料、分析合格和全流程试车节点。2020 年企业文章又涉及乙烯装置、聚烯烃包装和立体仓库。产业有相互联系的装置、检验和仓储，不是“按图纸分给几个工种就生产一桶油”。[中化泉州丙烯腈项目建成投产，2025-04-30](https://www.sinochem.com/sinochem/xwzx/zxdt/ywdt/2025/4/I1367158794810818560.html)、[天华院助力泉州乙烯项目，2020-10-12](https://www.sinochem.com/zghg/xwymt/qyxw/2024/10/I1294341936244588544.html)

**建议分开研究两条业务链。**

| 链路 | 企业主责资料与系统 | KANPACE 可研究的工作边界 |
|---|---|---|
| 连续生产与发运 | 生产计划、原料/产品规格、装置操作规程、化验结果、罐区和物流计划；原有控制、生产与实验室系统保持主责 | 先只读获取经批准的节点、异常、待办与交接，不接管装置设定值或反应过程 |
| 检维修/工程施工 | 设备位号、图纸、维修范围、检修计划、工作许可与隔离确认、备件、承包商、检验移交资料 | 以设备/检修包拆机械、电气、仪表等任务，做备件齐套、作业面交接、进度和验收证据 |

连续过程可概括为原料接卸/储运→经企业路线进入炼制及相关化工装置→中间物流/检验→产品储运或包装发运；这是业务对象层的产品推演，不提供技术操作步骤。不同装置联动、罐容、物流、公用工程及检修窗口都可能限制计划，不能由通用工种模板自动模拟装置产能。

**第一单切入。** 优先研究停工检修或非装置控制的维修协调：让承包商或班组收到设备位号、批准范围、图纸、备件、前置确认与验收清单。既有审批状态由主责系统提供，KANPACE 不自行宣布作业许可有效。现有缺料暂停/换单仅用于人员工作安排，不能变成停止、恢复工艺装置的命令。

**工牌边界。** 不能假定普通 ESP32-C3 开发板符合石化生产区设备要求。需按企业允许的区域、设备规格和接入方式选择终端；现原型可先在办公室、培训或企业指定的可用场景验证交底，进入现场另做硬件选型。工牌不充当工艺控制、安全联锁、应急或唯一许可系统。

## 6. 当前软件能共用与必须新增的能力

| 能力 | 现有基础可复用 | 新行业需补的差异 |
|---|---|---|
| 图文交底 | 项目、来源版本、图片、任务和负责人 | 样板/配方版本、模具号、批号、窑次、设备位号；别强制每行业都上传施工图 |
| 分工与交接 | 工艺依赖、人员技能、异常和交接 | 批次拆分/合并、跨外协交接及批次谱系；工序合格数与投入数分开 |
| 排程 | 人员/工位有限容量、准备/等待、插单预览 | 窑批兼容与装载、连续产线、料仓/罐/缓冲限制、批量资源，不能只改菜单名字 |
| 报工 | 累计整件、开停作业段与回执幂等 | 当前整件执行口径不能直接覆盖公斤、吨、面积与产线节拍；需要受控单位/换算及批次产出模型 |
| 质量 | 检验放行、返工和异常闭环 | 原料批、过程批、窑批与成品批关联；抽检结果作用范围明确，不能一条合格放行所有订单 |
| 工牌 | 当前任务、两图、开始/暂停/完成 | 依岗位换成样板、批次卡、配方步骤或设备图；人员动作与工艺/设备状态必须分开 |
| 客户保密 | 独立客户资料存储及账号 | 配方、色釉、样品和客户设计需岗位级最小显示；不能把客户配方自动合并成公共模板 |

最值得先补的共性是 **“批次及其拆合/流转关系”** 和 **“人员状态、设备状态、工艺等待三个时间轴”**。没有这两个模型，建陶、香、烧成等只是在界面上看似支持，实际排产和成本会失真。

## 7. 建议试点和现场核对问题

1. 安溪：一款含金属、木/藤部件的订单。验收批准样一致、分支齐套、外协数量交接和同产品包装配套，比较整理交底时间与现场追问。
2. 德化：一个日用或工艺 SKU 的成型至装窑批。验收合格/待修/损耗数量守恒、批号追溯、模具/窑次关联，避免首轮承诺全自动窑炉排产。
3. 永春：一个香品类型的配料到包装批。验收授权配方、晒架批次状态、包装批关联与等待时间，先不扩展全部香型和礼品类。
4. 晋江建陶：从一条线的换型、首件、异常、交接开始；确认客户现有 MES 能提供什么，经口径核对后才研究产量和计划互联。
5. 石化：从一个检修工作包验证图纸、备件、许可引用与验收移交，不把生产装置闭环控制纳入通用工牌试点。

每家只需先问清：什么是一个批/对象；哪些状态由谁批准；哪些工序不能随时暂停；哪一类资源决定交期；哪两份现有表互相对不上；外协交出去后怎么知道在哪；现场终端实际可用的区域与操作方式。所得答案决定模板，不先安装一套通用大表再要求工厂迁就。
