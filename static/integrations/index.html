API、CLI、MCP 各用其长

API 和原系统业务动作是互联基础，事件用于触发与追踪。CLI 适合脚本和诊断；MCP 让助手调用已授权的工具。工具名称相同，不代表拥有相同业务权限。

KANPACE可在统一业务服务上扩展 CLI/MCP。已购集成平台可以继续承担传输与映射，展示柜工艺和工程版本规则留在KANPACE。
