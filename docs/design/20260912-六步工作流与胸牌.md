# KANPACE 六步工作流与胸牌设计契约

## Decision summary
- Product: KANPACE Web + ESP32-C3 工牌。
- Primary user: 不熟悉软件的工厂管理者；双手正在作业、需要短时间看清任务的工人。
- Primary task: 管理者按日期准备和下发任务；工人看图完成一项、确认一项，遇到问题可暂停交接。
- Observable success: 导入→排程→派工→执行→贴标→归还均有直接入口；后台保存真实业务状态；重复请求不重复计量。
- Direction: Web 沿用 KANPACE 蓝白工程工作台；胸牌用烟灰外壳、黑白清楚内容、橙色动作键。任务大字与真实图纸占主要空间。

## Context and reference transfer
- 图 1 是六步顺序与异常回路的产品要求；当日标签准备横跨排程与现场。
- 图 2 提供外壳、摄像头位置、侧边滚轮及橙色按钮的外观参考。交互预览体现这些结构；当前 C3 没有据此增加物理摄像头或新 GPIO。
- 图 3 决定信息层级：工种/工人→柜名/部件→数量→大图；问题分类按需弹出。手写数字不进入真实生产数据。
- Runtime: 现有 Python/SQLite、原生 HTML/CSS/JS；C3 ST7789 170×320/CST816D。
- Inputs: 桌面键鼠、触屏；当前开发板触摸，未来外壳侧键在浏览器中模拟。
- Assets: 工厂资料从已授权本机接口读取；演示页使用既有标有水印的合成图片，不复制客户资料到公共资源。

## Direction contract
- Thesis: 每屏只回答当前工人“现在做哪件，怎么做，下一步点什么”。
- Palette: Web 复用 --blue #315ee8、--ink #202935、--paper #f5f6f8；胸牌 --badge-shell #303331、--badge-paper #fafaf7、--badge-action #f47b20、--badge-ok #237456、--badge-warning #9b4816。
- Typography: 系统中文字体；Web 工作流正文至少 16px、主要动作至少 44px；胸牌原生按物理像素排版，不能直接照搬浏览器 px。
- Composition: 工种/状态顶部单行；柜名和部件相邻；数量独立；图纸主区；固定底部操作。
- Signature: 一张施工大图与一个显眼的当前动作。
- Aesthetic risk: 半透明烟灰工业外壳仅用于硬件交互预览，界面保持亮纸面；不照搬参考图中的装饰声波。
- Restraint: 无循环动画、无虚构电量、无多余联网说明；图标有可访问名称。
- Motion: 仅用户触发的弹窗和按下反馈，支持减少动态效果。
- Copy: “开始做、完成、遇到问题、先做其他、确认贴标、归还胸牌”。说明只在操作需要时出现。

Challenge: 不把六步做成六套独立数据库，也不以多一套卡片代替原有功能。沿用原任务、工程版本、排程、角色权限与设备回执；新建标签和领还记录只保存本身生命周期。

## Shared / platform-specific decisions
| 语义 | Web | 当前 C3 | 外壳交互预览 |
|---|---|---|---|
| 当前任务 | 日任务列表、派工上下文 | 原任务下发协议与已收回执 | 只读真实任务或明确合成示例 |
| 看图 | 全尺寸原图/放大 | 本地任务绑定图片、按需放大 | 施工/效果切换与放大弹窗 |
| 异常 | 负责人、暂停和排程处理 | 分类确认后回传，等待业务回执 | 本地交互模拟，不写生产记录 |
| 贴标 | 稳定二维码、核对、确认 | 能力协商后确认，不能假装扫码 | 演示匹配与下一项 |
| 归还 | 当日未完成/未贴标拦截或明确交接 | 不混同设备收件或关机 | 显示未完成列表后才允许演示归还 |

## UX state matrix
| 场景 | 状态来源 | 呈现/恢复 |
|---|---|---|
| 无日期排程 | 后端实际计划 | 空状态，引导去排程；不把所有历史任务当今天任务 |
| 请求中/失败 | HTTP 响应 | 保持选择，按钮防重复；失败可重读，不自动重放写操作 |
| 任务未放行/缺料 | 原业务校验 | 原因与处理入口，不能通过派工绕过 |
| 完工待贴标 | 真实完成状态与标签记录 | 完成不等于贴标；错任务/旧版标签拒绝 |
| 异常暂停 | 工人操作+业务回执 | 明确暂停和待处理；可查看其他任务，保留已做数量 |
| 无图/错图版本 | 素材范围 | 说明需补图，不显示其他订单图片 |
| 断线 | 传输/事件队列 | 可读已缓存内容；待确认不伪装成功 |
| 归还受阻 | 当日领用任务和标签 | 列出剩余事项；不因跨日自动清空未完任务 |
| 弹窗关闭 | 用户触发 | 原生 dialog，Escape/关闭按钮，恢复焦点 |
| 真实任务预览 | 已授权只读 API | 无写入调用，交互结果不改变工厂记录 |

## Acceptance evidence
隔离演示库验证 API、二维码可解码、浏览器六步导航、异常/标签/归还状态、窄屏与键盘；固件 host 测试和实际编译。当前无 USB 开发板串口，实机显示与实体按键未验证。具体结果记录在对应验证报告。
