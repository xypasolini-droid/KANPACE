# 柜序 · UX 状态矩阵

本矩阵依据本地 SPA 与 API 的实际状态命名整理。各项属于界面和业务验证清单；通过证据与已修复缺陷由 `UI-QA-REPORT.md` 记录，未在本文件虚填通过结果。

## 主流程与入口

主流程：项目 → 导入工程资料 → 构件复核 → 生成工序草稿 → 发布工程版本 → 技能派工 → 开工 → 完工 / 异常处理 → 导出与追溯。

| 入口 | 已知上下文 | 返回目的地 | 恢复范围 |
|---|---|---|---|
| 首次打开本机URL | 可含内置演示项目 | 图纸拆单或项目列表 | 服务端持久化数据 |
| hash项目链接 | page、tab、project | 主导航与该项目标签 | 当前页面及项目 |
| 刷新页面 | hash与最近项目 | 同页面 | 已保存数据；不恢复未提交表单 |
| 打开构件/任务dialog | 当前项目及对象ID | 原页面 | 未关闭dialog期间输入保留 |
| 浏览器重新获得焦点 | 当前已加载页面 | 原页面 | 无dialog时重新读取服务数据 |
| 本地服务未启动 | 无可用数据 | 启动说明与重试 | 重连成功后重新读取 |

## 页面状态

| 页面 / 组件 | 状态来源 | 用户可见反馈 | 可用动作与恢复路径 | 持久化与辅助输出 |
|---|---|---|---|---|
| 应用启动 | 首次请求未完成 | “正在打开本地工作台…” | 等待；失败显示启动与重连提示 | 初始HTML文字；无虚构项目数据 |
| 服务错误 | API请求失败 | 页顶错误或dialog错误；短提示 | 保留当前页面并重试连接 | 错误不能代表新数据已保存 |
| 项目列表 | projects为空 | 新项目入口 | 创建项目后进入图纸拆单 | 服务器SQLite保存项目 |
| 新建项目 | 编辑中 | 名称、客户、交期、套数字段 | 取消或创建；缺必填项原生校验 | 未提交字段不持久化 |
| 导入dialog | 文件已选、请求进行中 | “正在保存…”；按钮禁用 | 等待逐文件响应 | 单文件API事务；已完成文件已保存 |
| 结构化BOM | parsed / needs_review | 真实构件及来源行号 | 逐项复核、修改、确认 | 原件归档；初始review_status=pending |
| 原生CAD/PDF | needs_conversion | “待转换”与能力说明 | 导出BOM/DXF或手动补录，登记依据 | 原件可下载，不生成虚构解析构件 |
| 不可解析内容 | error | 解析失败与具体warnings | 修复文件重导或补充依据 | 失败记录与原件保留 |
| 无构件文档 | part_count=0 | 无构件/待补录 | 导入替代BOM或录入并复核 | 发布端应阻断未核验来源 |
| DXF预览 | 实体geometry | 真实DXF实体标签 | 查看来源、缩放/重置 | 图层与句柄随geometry保留；单位未知不得当成mm |
| BOM尺寸预览 | 明确长宽的部件 | “BOM尺寸示意 · 非装配图” | 核对构件字段 | 不伪装成原生装配解析 |
| 演示关系图 | project.demo=true | 演示项目、非CAD解析说明 | 可试用完整操作；真实项目另建 | 所有演示指标均属于本地样本 |
| 构件待复核 | review_status=pending | 待复核标签与缺项 | 编辑后保存待复核或确认构件 | 错误在dialog内说明，保留输入 |
| 构件缺关键数据 | 服务端part_blockers | 拒绝确认并列出字段 | 补材料、类别、尺寸、数量、做法 | 缺失数值不被填成0 |
| 构件已复核 | approved | 已复核标签 | 查看或改动关键字段 | 修改影响工程版本及任务有效性 |
| 草稿工序 | task.status=draft | 草稿分组与规则依据 | 检查依赖、发布、安排人员 | 草稿不允许实际报工 |
| 发布被阻断 | 未复核/未转换/版本不一致 | 具体阻断原因 | 返回复核、补充资料或重新生成 | API保持原状态 |
| 发布成功 | project.status=released | 已发布，草稿任务变待开工 | 派工与执行 | 保存该工程版本发布快照 |
| 待分派 | assignee为空 | “待分配人员” | 选匹配工种人员或按技能派工 | 无负责人不得开工 |
| 无匹配技能 | eligible为空或服务端不匹配 | 无可选人员/技能不匹配原因 | 维护人员技能，重新分派 | 不能把不匹配的选择当作成功 |
| 未完成前置 | dependencies含非done | 前置完成数量与开工阻断 | 完成正确前序后重试 | 最终门禁在API，不能仅依赖禁用按钮 |
| 正在执行 | in_progress | 进行中，显示负责人和工时假设 | 完工或异常暂停 | 保存开始时间；执行中改派需先暂停 |
| 异常暂停 | blocked | 异常分组，任务备注 | 记录原因，解除后恢复执行 | 异常/解除理由应在事件记录可回查 |
| 已完成 | done | 已完成分组 | 查看任务与验收依据 | 完成事件持久化；不可直接回退 |
| 工程变更 | invalidated或项目revision提升 | 变更待重审与版本提示 | 复核变更并处理受影响任务 | 已完成的真实执行事实须保留；不可默默重发无关工序 |
| 报价未完整 | complete=false | 未计价项目与原因，完整总价为空 | 补充计价量、单价与费率 | 展示已知分项，不把缺项作零 |
| 报价可计算 | complete=true | 内部估价与透明公式 | 校准费率并人工复核 | 仍是provisional草稿，不等于对外批准价 |
| 表单保存错误 | 400/409/500或请求失败 | dialog-error / settings-error | 修正或刷新后检查已保存状态 | role=alert；不清空输入 |
| 表单保存成功 | API成功响应 | 刷新视图与成功toast | 返回当前流程 | toast为role=status、aria-live=polite |
| 长文案/长文件名 | 来源、备注或数据较长 | 折行/表格区域横滚 | 阅读和打开详情 | 不以隐藏溢出丢弃工程含义 |
| 键盘聚焦 | focus-visible | 操作蓝轮廓 | Tab、Enter、Escape | dialog带标题；按钮与链接有明确名称 |
| 窄屏 | CSS断点 | 导航横排、工作区与表单单列 | 原动作仍可访问 | 宽表在自身容器滚动；需实测320px |

## 事务与恢复约定

- 事实源：SQLite中的项目、部件、任务和事件；原始上传文件另外保存在本地uploads目录。localStorage只保存最近项目，不承担业务数据存储。
- 重复提交：前端禁用正在提交的按钮；同一有效项目中相同文件内容哈希避免重复导入；同版本重复生成保持现有任务；重复done返回原完成状态。其他写操作并未统一提供客户端幂等键。
- 结果不明：连接中断时先刷新核实实际状态。API响应丢失不代表事务未提交；不要提示已失败并要求盲目重复创建。
- 多文件导入：逐文件独立提交，中途失败时此前文件可能已经保存；重试应利用哈希去重并说明已完成部分。
- 未保存编辑：dialog关闭、页面刷新或浏览器关闭会丢弃本次未提交输入；不承诺自动草稿。
- 工程变更：保留源资料、修订和历史任务，不覆盖已经发生的执行事实。新增/改图后需要重新核查工程门禁。
- 发布：有明确确认dialog和服务端校验；发布快照记录被批准的工程版本。
- 取消/撤回：当前没有通用Undo，也没有把完成工序简单回退的操作。需建立有理由的工程变更或后续返工机制。
- 离线：应用不依赖云端，但浏览器仍依赖本机服务。尚无Service Worker离线提交队列、设备协议或多机同步；服务关闭时不能继续写业务数据。

## 平台与实测边界

浏览器前进、后退和刷新通过hash恢复页面上下文；多个标签页共享同一个SQLite事实源，当前并未实现每字段冲突合并或完整乐观锁。不同用户账号隔离也未实现。主页面和弹窗的实际键盘顺序、屏幕阅读器输出、窄屏溢出和断线恢复须在运行应用上验证，并写入QA报告。

iOS原生、Android原生、微信小程序和智能胸牌没有对应客户端，因此不存在已验证的原生返回栈、系统重建、刘海安全区域、胶囊导航或设备离线行为。
