# 柜序 · 实现设计系统

此文档以 `static/style.css`、`static/index.html`、`static/app.js` 为实现依据，并沿用 `DIRECTION.md` 的工程审图桌方向。它不宣称存在 Figma 设计库或移动端原生组件。

## 设计主张

工程图纸与构件表是视觉主体，右侧复核区解释当前缺什么和下一步能做什么。图号、数量、尺寸和费用使用等宽数字；岗位、工程状态和数据来源通过文字与克制的语义颜色区分。品牌表现集中在窄导航和工程纸面，表单、表格与按钮保持熟悉。

方向选择：审图工作区优先于通用统计卡片首页，因为技术员必须先确认事实再派工。生产概览作为独立页面保留，不用无依据的准确率或利润提升图表支撑产品形象。

## 颜色与字体

| 语义 | 当前 CSS 值 | 用途 |
|---|---|---|
| 页面纸面 | `--paper: #f5f6f8` | 应用背景、安静的页面分区 |
| 面板 | `--surface: #fff` | 图纸、表格、表单、弹窗 |
| 正文 | `--ink: #202935` | 标题、正文和关键数据 |
| 次要文字 | `--muted: #657080` | 来源、规则依据、辅助说明 |
| 细边界 | `--line: #e6e9ee` | 面板、表格、栏位分隔 |
| 主要操作 | `--blue: #315ee8` | 当前导航、主要按钮、键盘焦点 |
| 操作浅底 | `--blue-soft: #edf2ff` | 活动导航、规则标签、复核图标 |
| 警示 / 工艺 | `--amber: #946426` | 待补充、演示、木作标签 |
| 正向状态 | `--green: #287253` | 已完成、已确认、服务正常 |
| 错误 | `--danger: #b94139` | 错误说明、异常操作 |

状态不能仅靠颜色传达，始终同时提供“待复核、异常暂停、已完成”等文字。焦点采用 2px 操作蓝轮廓，outline-offset 为 3px。

| 文本用途 | 字体 | 尺寸与行高 | 字重 |
|---|---|---|---|
| 页面标题 | 系统无衬线 | 桌面 24px，窄屏 22px；1.4 | 650 |
| 普通二/三级标题 | 系统无衬线 | 16 / 14px；继承 1.6 | 650 / 600 |
| 面板标题 | 系统无衬线 | 13px；继承 1.6 | 650 |
| 基础正文 | 系统无衬线 | 14px / 1.6；页面辅助正文常用 12px | 常规 |
| 表格、表单、按钮 | 系统无衬线 | 10–12px；标签常用 10px | 常规或 500 |
| 尺寸、数量、费用 | SFMono-Regular / Consolas / monospace | 随容器 10–34px；tabular-nums | 常规 |

系统无衬线顺序为 `-apple-system, BlinkMacSystemFont, Segoe UI, PingFang SC, Microsoft YaHei, sans-serif`。不下载字体，不增加字体授权资产。小字号密集信息须在目标设备上验证可读性，不能用桌面截图代替现场设备测试。

## 布局、密度与层次

- 桌面壳层：208px 固定导航与自适应主区；顶部栏 66px；主要内容常规留白 28px/32px，最大宽度 1800px。
- 审图双栏：主区与 320px 复核侧栏，间距 20px；1600px 以上侧栏为 360px，图纸高度增加。
- 间距以 4/8/12/16/20/24/32px 为常用步长。面板 8px、控件 6px、dialog 12px 圆角；大多数内容通过边框分层，只有 dialog 与 toast 使用显著阴影。
- 工程纸面：浅点阵背景，DXF 预览或明确标记的构件示意；SVG title 保留实体图层/句柄，不把示意造型伪装成装配模型。
- 表格：nowrap 与独立 `.table-wrap` 横向滚动，避免列头和数值错行。
- 看板：桌面四列，1190px 以下两列，680px 以下一列；每列包含明确标题和任务数量。
- 1190px 以下导航缩至176px；960px 以下审图区和报价区单列；680px 以下导航变为顶部横向可滚动栏，表单改为单列。

## 组件契约

| 组件 | 用途与变化 | 交互/状态约定 | 可访问性 |
|---|---|---|---|
| 主导航 `.nav-link` | 页面切换与当前页面 | 活动浅蓝底；hash 路由 | 主导航带 aria-label；活动链接使用 aria-current |
| 主要按钮 `.btn` | 导入、发布、保存、开工 | primary / quiet / danger；disabled 降低透明度；提交时“正在保存…” | 真实 button；禁用态与文本反馈 |
| 图纸面板 `.drawing` | 显示真实实体或尺寸示意 | 缩小、重置、放大；来源文件入口 | SVG role=img、用途标签；图纸工具按钮有 aria-label |
| 构件表 | 来源与尺寸材料并列 | 点击构件进入复核；显示选中行和审核状态 | 真正 table；可点击入口为 button |
| 复核侧栏 | 当前完整性与下步动作 | 未复核显示补充提示；无构件时禁用生成入口 | 文字解释缺项，不单靠进度色条 |
| 任务卡与泳道 | 工种、版本、依赖和人员 | 草稿/待开工、进行中、异常/重审、已完成四组 | 任务卡使用button，可键盘打开 |
| 状态标签 `.badge` | 工程与任务状态 | blue / green / amber / red | 颜色始终附带状态文字 |
| 表单 `.field` | 构件、人员、计价输入 | required / min / max / step；服务端校验仍为最终依据 | label 包含控件；原生错误定位 |
| dialog | 聚焦单项复核和报工 | showModal/close；保留错误时输入；提交成功关闭 | aria-labelledby，原生焦点约束与Escape行为 |
| 错误条 | 数据或服务失败 | 保留错误文字，提供“重试连接” | 弹窗错误为role=alert；页面错误仍需实测阅读顺序 |
| toast | 已确认操作反馈 | 底部短暂出现；不作为持久错误的唯一位置 | role=status、aria-live=polite |
| 报价摘要 | 分项成本及内部估价 | 未计价时保持空缺，显示原因；统一人民币 | 表格与文字公式并存，无单纯图形金额 |

## 状态、导航与内容

路由使用 `#page=...&tab=...&project=...`。页面切换读取本地 `/api/state`，报价页面另读取项目报价；最近项目写入 localStorage。dialog 是暂时编辑区，未保存输入不会持久化。数据操作经过本地 API 成功响应后刷新，不把请求发出当作已保存。

按钮使用具体动作，如“继续构件复核”“发布任务”“开始工序”“提交完工”“异常暂停”。错误说明应指明缺失字段、前置任务或旧版本原因。空态给出导入或生成入口。工时标注为规则估算；示例项目标“演示”；报价标“内部测算”，不能用“已解析”替代“可投产”。

长来源、哈希与详情采用 `overflow-wrap:anywhere`；表格字段可横滚。文件名、备注和图层内容进入HTML前使用转义函数。

## 动效与平台边界

仅有按钮按压位移与toast的150ms透明度/位移动效；不存在长时间背景动画。`prefers-reduced-motion: reduce` 关闭动画、transition与平滑滚动。弹窗使用浏览器原生modal交互。

当前仅Web实现，尺寸单位为CSS px。iOS、Android、微信小程序没有单独实现、组件替代或设备验证。手机响应式页面不等于已实现手机访问本地服务，更不等于智能胸牌端。

| tokens、布局、断点、组件外观 | `static/style.css` |

禁止：虚构识图准确率、伪装CAD装配预览、用零价代替缺价、只用颜色区分状态、没有确认响应就提示成功、隐藏示例身份、将本地岗位设置写成真正的账号授权系统。
