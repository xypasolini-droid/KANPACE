# 3D 拆单工作台

2026-09-05。复用本地 Web 服务与工程审图桌的字体、颜色和操作命名，新增独立的模型工作区。入口为 `/model/index.html?project=<项目 ID>`，已打开的正式模型使用 `document=<文档 ID>` 保留刷新入口。

主要任务：技术员打开现有模型，选择可见结构，核对模型包围尺寸，并明确关联到已有拆单项及其工种工作范围。示例模型单独标示，不创建订单构件。

## 页面组成

- 左侧为本项目模型文件和实际模型结构；节点支持选中、隐藏、显示全部及隔离。
- 中部为真实三维视图，提供透视等轴和正交前视 / 俯视 / 右视、旋转平移缩放、适应、爆炸与 X / Y / Z 剖切。
- 右侧展示选中节点的模型包围尺寸，并将它与本项目当前拆单项关联；关联后显示订单数量、材料、规格及工种工作范围。
- 窄屏按模型 → 文件与结构 → 拆单详情排列，不缩小三栏到不可操作。

## 文件与几何

GLB、OBJ、STL 使用本地 Three.js；STEP、IGES、BREP 使用本地 OCCT WebAssembly Worker。所有库随应用保存，不依赖在线 CDN。GLB 只接受内嵌资源；OBJ 不主动请求外部 MTL / 纹理。

单文件上限 20 MB，输出网格预算 50 MB，最多 2500 个网格节点。OCCT 最长 90 秒，取消或切换模型会终止 Worker；旧请求和旧单位保存响应不会覆盖新模型。STEP 未读取到实体时提示导出包含全部零件实体的单个 STEP 文件。

网格节点使用稳定遍历键 `mesh-N`，与订单数量分开。此版本不自动将几何实例计为 BOM 数量，不生成机加工程序或改写 CAD 实体。

## 单位与关联

STEP / IGES 统一转换为毫米；GLB 使用米；STL / OBJ / BREP 须人工选择原始模型单位，单位未选时不能测距。显示的包围尺寸和两点距离统一换算为毫米。两点测距基于三角网格表面的点击位置，明确标注近似测量；启动测距会收拢爆炸视图。

单位及模型节点与拆单项的关联由 `/api/documents/<id>/model-links` 保存。只有已确认保存后才显示成功。拆单项归档或修订后，原关联显示“拆单已更新，重新确认关联”，不继续呈现已关联工种详情，用户可重新关联或解除。

剖切用于内部结构查看，当前不生成实体剖切封口。SolidWorks 原生编辑、原生 3ds Max 场景编辑及参数化建模不属于此工作台已实现能力；需导出当前支持格式。

## 验证记录

Node 语法检查：`static/model/app.js`、`static/model/occt-worker.js` 通过。

`node tests/test_model_frontend.cjs` 通过 GLB 外部资源限制、几何预算、单位保存失败回滚、旧模型响应隔离及过期 BOM 关联提示回归。

主任务浏览器已反馈：GLB 示例显示 11 个实际节点；隔离侧板的模型包围尺寸为 18 × 800 × 600 mm；爆炸及剖切可操作；真实 STEP 上传得到 2 个 10 mm 实体，关联 Cube_A 到 Cube A 后 UI 显示其订单数量 2 件。刷新恢复模型、测距及更多响应式 / 键盘验证继续由主任务记录，不以静态测试替代。


最终浏览器验证：真实双立方体 STEP 的前视两点近似测距为 19.99 mm（实体中心间隔 20 mm）；刷新后恢复正式模型及已保存的 BOM 关联。390 px 窄屏实测无页面横向溢出。关闭项目仍可查看模型，上传、单位和零件关联修改被禁用，后端同步拒绝写入。
