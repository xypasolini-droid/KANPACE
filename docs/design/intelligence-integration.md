# 本地工程能力接入设计

沿用现有 Web、原生 dialog、品牌、蓝色操作按钮和岗位权限。主要用户是50岁以上老板及40岁以上管理者；一次只做识图复核、模型核对、排程或排料中的一项。

入口：图纸与拆单中的“识别图纸 / 核对模型”；成本报价中的“板材排料”；产能与插单中的“优化排程”；现有操作助手。不开新的顶级菜单。

识别结果采用左右对照：左侧原图与位置框，右侧原文清单；选取证据后进入现有构件编辑和待审核流程。模型核对列装配实例、单位、外包尺寸、面积体积，外包尺寸不直接填为下料尺寸。排料使用已确认的同材同厚下料尺寸，绘制实际求解布局。排程保留候选预览和确认采用。

| 状态 | 反馈与恢复 |
|---|---|
| 首次/空 | 选择本项目文件；无文件显示上传入口 |
| 运行 | 本地处理与真实进度，不造百分比；可关闭，记录保留 |
| 完成 | 原图证据、几何表或排料布局；明确下一步复核 |
| 失败 | 原因留在记录，输入不清空，可重试 |
| 离开/回来 | 根据当前项目读取已保存处理记录，不把旧项目结果覆盖新项目 |
| 权限/退出 | 服务端岗位校验；退出清空弹窗、轮询与缓存 |
| 工程变化 | 原始哈希和版本校验；旧识别不得静默成为当前制造依据 |

控件使用已有变量 --ink/--muted/--line/--blue；新表单正文至少16px，按钮至少44px，间距8/16/24。图文对照宽屏两栏，窄屏上下排列。native showModal支持Escape、可见关闭按钮；关闭恢复触发按钮焦点。无循环动画，处理状态aria-live，图示带文本列表替代。

范围是接入五个真实开源引擎；不自动发正式任务、改变已发货状态、猜测CAD工艺或把OCR当已审核下料尺寸。客户资料、本地任务记录、识别结果与助手状态保存在该工厂data目录。
