# R33 排程与整单派工

用户：不熟悉软件的工厂管理者与现场工人。目标是沿用 Excel 排程习惯，以订单资料为依据拆解、按项目派工，工人拿到完整图册。

## 方向与范围

保留 KANPACE 现有蓝色操作、灰白背景、清晰文字与六步导航。去掉第一步独立工程模型与报价入口；排程表承载关系、周期和顺序修改；物料需求与采购来自拆单净用量；工人缺料从现场异常处理。派工按项目与工人绑定胸牌，图片跟随任务，不再另发图片。

挑战：不能为了减少页面而取消工程版本、任务前序、进行中任务和回执保护。它们在原动作处检查和说明，普通用户不再先进入空泛的检查页。未知库存不当零，推断工期带来源，采购仅形成可审核草稿。

## 页面和状态

- 资料：工程图与效果图共存；效果图只作外观参考。多图可查看来源、翻页、并排对照。
- 排程：导入成功后显示解析结果；关系周期可编辑；覆盖新表前说明范围与差异；已执行记录保留；未映射工序不能假装已排产。
- 物料：读取中、无清单、缺尺寸、待复核、库存未知、净缺口、采购草稿、版本已变化。可用库存按交期测算分配，不产生实际扣库。
- 派工：项目选择、每人胸牌绑定、连接数量、预览、发送排队、设备回执、图片回执、断线等待、重试与过期失效。
- 图册：无图、读取失败、任务切换、单图、多图、两图核对、窄屏上下排列。

Web 使用语义表格与原生 dialog；操作按钮保留文字、可键盘使用，主要触控目标44px以上。复杂表格允许表内横向滚动，页面本身不溢出。现有数据、许可和隔离规则保持。
