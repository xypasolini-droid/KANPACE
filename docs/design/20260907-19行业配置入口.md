# 19 行业配置入口

## Decision summary

- Product: KANPACE 中台行业配置与工厂工作包。
- Target platform and runtime: 本地 Python/SQLite、原生 JavaScript Web；保留现有接口、权限和版本。
- Primary user: 工厂实施人员、50 岁以上制造业老板和40岁以上管理者。
- Primary task: 从已调研行业及生产类型生成可核对的工厂流程草稿。
- Observable success: 19 行业均能选择；类型对应真实独立 DAG；选择后填本厂名称、复核与启用，工厂收到对应模板和对象字段，能生成待审核工作包。
- Recommended direction: 现有白色工作纸、蓝色主动作；行业列表用中文名称与分组，右侧预览实际资料、对象、工种和串并行。

## Context

入口 `/control/index.html`；研究地图可直接进入对应行业。先公开查看通用参考，再登录操作客户配置。目录来源是既有 19 行业调研，不向公共目录混入客户文档、账号、报价或实绩。

沿用 KANPACE 官方字标。语义色：白色纸面 #fff、底色 #f5f6f8、正文 #202735、次要 #596579、蓝 #345bf5、待核对 #9a610b。系统中文字体，正文/控件16px、说明14px、标题24–30px；点击区44px；只保留反馈动画。

## Scope

行业与原有三类运行场景分开储存。行业决定参考路线、对象叫法、资料、字段和工种；现有底层运行场景保持兼容。食品、茶、石材、纸品等生产类型不得合并为一条路线。

批次路线以一个完整批次工作包为整数执行对象，重量/面积/型号等作为独立字段，不把现有任务数量冒充公斤或平方米。工时未知留空；生产参数、配方和法规验收阈值由企业确认。

## First delivery slice

| Screen | Intent | Primary action | States |
|---|---|---|---|
| 行业库 | 找本厂所属行业/生产类型 | 选择行业与类型 | 19项、搜索无结果、未登录可看、错误重试 |
| 类型预览 | 看生成内容是否适合 | 使用这份行业流程 | 资料清单、节点依赖、工种、来源与待核对 |
| 工厂配置 | 校正本厂具体做法 | 保存并预览 | 新工厂/既有工厂、旧草稿保留、确认替换、来源版本过期 |
| 工厂工作包 | 按本行业填首单 | 保存待审核工作包 | 行业专用字段、缺项保留、审核前必填、原任务不改 |

## Direction challenge

不能只新增19个下拉选项：每项必须有对象、路线、岗位、资料和可用字段。不能因为登录页挡住而看不到行业库。不能把批次工艺当作每个零件走全套流程。变更行业要保留已填内容直到用户明确应用；不能静默覆盖草稿或已有在制模板。

## Acceptance evidence

临时数据库验证全部行业/类型的草稿、预览、启用、模板字段传递；错误行业及变体拒绝、版本过期和幂等保留、隔离。浏览器验证未登录目录、按行业开通、切换类型、替换确认、企业模板与工作对象字段、窄屏、键盘和错误状态。实际用户数据库只读。
