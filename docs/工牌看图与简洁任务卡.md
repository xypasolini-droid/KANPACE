# 工牌看图与简洁任务卡

工人的默认界面是一张当前任务卡。它回答项目与部件、当前工序、已做和剩余数量，并按任务状态显示下一步操作。任务资料不再逐项排成必须依次浏览的页面。

## 日常操作

| 当前状态 | 首页操作 | 结果 |
|---|---|---|
| 待开工 | 开始 → 确认 | 服务端核对负责人、版本、前序和开工条件后更新状态 |
| 进行中 | 暂停 → 原因 → 确认 | 保留已登记进度和现场交接 |
| 进行中 | 完成 → 确认全部数量 | 服务端核验完成条件；需要检验记录的任务仍须完成验收 |
| 已暂停 | 恢复 → 确认 | 服务端核对暂停解除条件 |

未收到业务确认时不会把任务画成已完成。演示卡保留测试标识，不把查看图片、翻阅要点或设备接收记录算作真实报工。历史没有逐件记录的任务，已做／剩余显示未记录。

遇到急单时，可在 Web 使用既有“暂停并换做”，保存原任务进度后再下发新的任务卡。仅发送另一张卡不代表原任务已经暂停，也不会自动开始新任务。当前工牌保存最后一张任务卡，尚不提供多任务离线队列。

## 查看施工图和效果图

1. 在 Web 进入“开发板联动”，通过 USB 连接支持看图的工牌。
2. 在图片区选择项目。缩略图均来自该项目已经登记的施工图或效果图，可放大核对原文件与页码。
3. 施工图和效果图各选一张，可以取消其中一类，然后发送。每个工牌图册最多保存这两类各一张。
4. 显示“已接收”需要设备确认完整字节、SHA-256 和 JPEG 解码。发送失败会保留失败原因，重新选择并发送即可。
5. 工牌打开图册后，用上一张／下一张切换施工图、效果图；用 −／＋切换 1、2、4、8 倍，放大后按图片区域的方向箭头移动局部。返回按钮或短按 BOOT 回到任务卡。

从项目图片区手工发送的是“项目预览”，不会发布草稿工程或更改生产任务。预览画面保留项目与预览标记；正式任务附图绑定任务、项目和工程版本，换任务后不会把旧任务图当作新图。

USB 下发正式任务并收到回执后，会尝试附带该任务明确关联的施工图和项目效果图。没有可靠任务关联的施工图不会自动充当该任务的施工依据；可在 Web 明确选择对应页预览。

## 图片和数据

- 图片由原始资料本地生成，不根据柜体尺寸推测效果，不从其他项目借图。重复像素图片在选择列表中合并，来源仍保留。
- 屏幕为 170×320，图片窗口为 160×224；设备保存 1280×1792 的完整画面 JPEG，再放大查看局部。整页密集标注需要放大；换页需要在 Web 重新选择对应的施工页。
- 每张 JPEG 最多 180,000 字节。编码保留画面比例、白边和原图完整范围；极复杂图片会降低编码质量或细节比例以适应容量，不补画原图不存在的内容。
- 只有传输完整、摘要匹配且可完整解码的图片才提交到图册。图册保存在 LittleFS，重新上电可以从首页再次打开。
- 当前图片传输使用 USB。已有 Wi-Fi 任务通道保留；图片无线传输不在本版实测范围内。

Web 接口见 [DEVICE-API.md](DEVICE-API.md)，工牌底层传输见 [IMAGE-PROTOCOL.md](../firmware/goldenmorning-display/IMAGE-PROTOCOL.md)。实际刷写、接收和回归范围以本轮验收记录为准。
