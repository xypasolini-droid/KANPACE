# KANPACE 生产排程

本地服务的排程接口、业务约束、请求示例和验证结果见 [生产排程接口与隔离测试](verification/production-planning-qa.md)。

排程入口：左侧“生产排程”。先建立真实人员并核准日容量，完成构件与工艺复核、发布工序、分派负责人，再从待排工序中安排日期。工作周在“工作日历”设置。

可查看周表和跨项目人员负荷，记录齐套，调整日期或撤销占位，导出 CSV。保存计划不会自动报工；缺料暂停需处理齐套和交接后恢复。已完成、已发货及旧工程任务退出活动计划，历史保留。

这是人工确认的按日容量计划：没有分钟级班次、设备瓶颈、节假日例外或自动优化。前后工序按不同工作日衔接；库存尚未接入，齐套需人工确认。
