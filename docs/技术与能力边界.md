# 展示柜本地拆单：技术与能力边界

这版软件把“销售项目 → 工程资料 → 构件清单 → 多工种任务 → 审核分配 → 报工/异常 → 成本草稿”做成本地可操作流程。重点是展示柜行业的木工、五金、油漆、玻璃、电工、装配、质检与包装协作。它使用明确的解析规则和工艺模板；当前不需要大模型密钥，也没有把未接入的识图模型、ERP 或智能工牌显示成已经接通。

用户提供的《施工图拆解为工种任务》和《工厂智能胸牌》作为需求资料使用。其中“工程事实、版本、工艺规则、人工审核、异常闭环”的思路转化为本地功能和后续接口约定；文档中的建议、示例和未来路线不代表已经实施或已经授权连接外部系统。

## 当前可以处理什么

| 输入/功能 | 本版做法 | 不能直接认定的事情 |
|---|---|---|
| CSV / JSON BOM | 读取明确的名称、材料、分类、长宽厚、数量、来源，形成待审核零件 | 缺字段不等于零；不能凭名称补出尺寸或数量 |
| ASCII DXF | 解析支持的线、文字、圆、折线、块引用及约定元数据；保留图层和实体句柄 | 未标注的平立剖视图不是生产 BOM；块引用不等于已展开完整几何 |
| 原生 SOLIDWORKS | 提供 Windows 端只读导出脚本，将当前装配实例/属性转为 CSV | macOS 网页没有直接读取 `.sldasm` / `.sldprt`；桥接尚未经过 SOLIDWORKS 实机验证 |
| DWG | 标明需要转换；使用 CAD 软件或单独安装的转换器先导出 DXF | 文件上传成功不表示已经解析 DWG |
| STEP / PDF / 图片 | 保留文件状态并提示适配或转换需求 | 没有实现完整几何内核、OCR、多视图关联、BOM 语义识别 |
| 工种任务 | 按已知构件分类和工艺规则产生任务草稿及先后关系 | 模板不能自动涵盖所有特殊节点、外协责任和厂内设备条件 |
| 报价 | 使用显式料价、计价单位、损耗、工时费率、外协与间接费计算可追溯草稿 | 示例料价/工时不是本厂真实成本；缺必要成本不得给出完整报价 |
| 工人执行 | 本地岗位、任务和事件流程供试用 | 已另增 ESP32-C3 任务显示链路；定位、NFC、语音硬件和 ERP 未接入 |

本地使用包含“导入、拆解、审查、操作与存储都在本机”的含义。多电脑协作、远程访问、移动终端可靠同步、备份恢复策略、统一身份和企业权限仍需要在实际部署条件下实施及验证。

## 展示柜的工艺重点

展示柜不能只按“木板给木工、金属给五金”分任务。一个柜体往往同时包含承重结构、木作基层、饰面、金属包边、玻璃门、灯带和驱动电源；最终装配需要这些分支的完成条件同时满足。

本版模板提供可检查的工序骨架。试点时应由技术员按本厂做法补充：木作开料/封边/开槽/试装顺序，金属激光/折弯/焊接/打磨/表面处理，玻璃磨边/开孔/钢化外协，油漆基层和养护要求，电气布线和通电检查，以及装配、包装、发运的放行条件。特殊涂层、防火材料、重载结构等要求必须来自本次工程资料，不能由模型或通用模板决定。

应优先形成四类本厂知识：经批准的部件分类表、按材料和做法区分的工艺模板、各岗位的技能/设备范围、带生效日期的成本费率。积累人工修订理由后再考虑增加模型；“有 Agent”本身不是效果指标。

## 与 MES、ERP 的责任边界

| 事实 | 推荐负责系统 | 本地拆单工具负责什么 |
|---|---|---|
| 客户、销售订单、合同价、税务和财务账 | ERP 或现行受控台账 | 引用订单编号，输出拆单和成本依据 |
| 图纸、配置、工程 BOM、工程变更 | CAD/PDM/PLM 或受控工程档案 | 保留源文件、版本与构件关联，生成审核草稿 |
| 实际库存、采购到货、领退料 | ERP/WMS | 消费明确的物料状态；未同步时不声称已经齐套 |
| 人员任务、工序依赖、完工/异常事件 | 本工具试点范围或已有 MES | 明确唯一负责系统，避免同时改两份生产状态 |
| 质量放行、处置和复验 | 质量负责人/QMS | 关联验收条件和记录，质量判断须有依据 |
| 工资与考勤 | HR/薪酬系统 | 工序报工不自动等于工时工资或考勤结算 |

接入已有系统时先约定稳定 ID、字段主责、变更顺序、失败重试和冲突处理，再开发适配器。这个版本不需要用新软件替换已有财务、采购和库存系统。

## 黑湖公开能力与公平比较

2026-09-04 核查的 [黑湖科技官网](https://www.blacklake.cn/) 已公开展示拆单、报价、企业工艺与设备规则、排程/履约风险以及生产经营分析。官网将图纸、表格和业务信息识别后生成任务列为拆单能力。官网展示的服务规模、精准度和收益属于厂商公开陈述，本项目没有独立复核其样本口径。

因此，本项目不能声称“因为做了拆单 Agent 就比黑湖强”，也不能根据网页展示断言竞品缺少某项功能。未购买或试用对方软件、未在同一套展示柜图纸和规则下测试，就没有可成立的性能排名。

| 值得比较的项目 | 对方公开情况 | 本工具目前能提交的证据 |
|---|---|---|
| 图纸/BOM 转任务 | 官网公开展示自动接入、识别与任务生成 | 可运行的结构化 BOM/约定 DXF 路径；原生图纸范围较窄 |
| 工厂规则与报价 | 官网公开展示企业规则参与报价、拆单和排程 | 本地可查的工艺模板、计价公式和缺价阻断；效果待真实费率验证 |
| 展示柜跨工种细节 | 官网通用介绍不足以判断具体覆盖范围 | 以本厂木工、五金、油漆、玻璃、电工样本逐项验收 |
| 本地运行和图纸留存 | 需向厂商确认具体产品与部署合同 | 当前可检查本地源代码和文件存储；企业部署能力待扩展 |
| 任务证据和改版影响 | 需用实际产品测试，不能假设其不支持 | 对源文件/版本/构件与任务的关联做可重复测试 |

竞争方向应是：用你们真实展示柜项目测出关键漏项更少、人工审核更快、成本解释更清楚、改图返工更可控。其他产品的宣传数字不作为我们的验收成绩。

## 建议的真实试点验收

建议从三个已完结且资料完整的项目开始，分别覆盖木作烤漆柜、金属玻璃柜和含电气模块的综合柜。再用两个未参与规则调整的项目做盲测。项目数量只是启动建议，不代表统计上已经足以证明泛化效果。

技术员先独立给出发布 BOM、工序及依赖、材料用量和人工报价基准。按完整项目划分调整集与测试集，重复柜型和同项目修改版留在同一组，防止把记住样本当作识图能力。

| 验收项 | 计算/记录方式 | 建议试点门槛，尚非实测结果 |
|---|---|---|
| 关键漏项 | 比对人工基准中的结构、电气、玻璃、外协和质量关键任务 | 放行前关键漏项为 0；一旦出现即修规则并复测受影响场景 |
| 数量和工程尺寸 | 明确来源的字段逐项核对；单独记录无来源字段 | 已填写字段与来源一致，缺失值不被系统偷偷补齐 |
| 多视图/多配置重复 | 同构件多视图、重复实例、不同配置分别验证 | 不按视图数重复计料，不错误合并不同配置 |
| 岗位与前置工序 | 逐任务核对主责岗位和全部直接依赖 | 无未完成前置任务的放行；无未知岗位的自动指派 |
| 证据覆盖 | 能回到文件、版本、构件/行号的任务占比 | 应追溯任务的来源覆盖 100% |
| 报价可重算 | 独立用料价、用量、损耗、工时和费率重算 | 各已计价行一致；缺价、缺量、缺必要尺寸阻止完整报价 |
| 人工审核时间 | 同一任务从导入至技术员确认的实际用时 | 建议目标比人工从头拆单减少 30%；必须包含改错时间 |
| 改版影响 | 预埋尺寸、材料、数量和做法变更，核对受影响项 | 每项变更都能找到需要重审的任务，不静默沿用旧放行状态 |
| 事件一致性 | 同一完成事件重发、乱序、断线恢复和旧版本任务提交 | 企业部署前保证不会重复记完成量或用旧版任务覆盖新版 |

准确率应分别报告“字段准确、任务召回、任务误报、数量错误、关键漏项、人工修改次数”。单一的“AI 置信度 95%”无法替代这些证据。

## 工牌与现场适配的下一步

已增加金逸晨 ESP32-C3 屏幕工牌的 USB/Wi-Fi 任务协议、Web 配网与回执记录；具体硬件验证结果见 `开发板联动.md`。实体“开始/结束/异常”报工、语音及离线事件同步尚未实现，下面是后续适配要求。

任务包至少包括任务 ID、项目和构件、图纸版本、任务版本、岗位、主责人、前置状态、完成条件和可用附件。每条上报事件至少带唯一事件 ID、设备 ID、人员 ID、任务 ID/版本、事件类型、发生时间、接收时间、数量与证据引用。网关需验证身份、任务状态和版本，并对重复事件幂等处理。

离线终端要能缓存已经批准的任务与待发送事件；重新连接后确认接收状态，遇到任务版本变更必须暂停旧任务执行并提示处理。语音按住录音、提交后保留原始文件，转写、修订与摘要分别记录。仅在硬件到位并完成真实测试后，界面才应显示“已连接/已同步”。

工牌用于任务和异常协同，不承担设备急停、安全 PLC 或唯一应急通信职责。首轮试点应先证明报工准确、异常有人接、处置能复验，再增加视觉或定位能力。

## 技术来源

- [SOLIDWORKS GetComponents](https://help.solidworks.com/2025/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IAssemblyDoc~GetComponents.html)：活动配置的组件列表；不能靠返回顺序推断层级。
- [SOLIDWORKS GetChildren](https://help.solidworks.com/2019/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IComponent2~GetChildren.html)：读取直接子组件，嵌套装配需递归；结果受配置和抑制状态影响。
- [SOLIDWORKS GetModelDoc2](https://help.solidworks.com/2022/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IComponent2~GetModelDoc2.html)：轻化、抑制或未加载组件可能返回空。
- [SOLIDWORKS Get6](https://help.solidworks.com/2025/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.ICustomPropertyManager~Get6.html)：读取属性原值与求值结果；缓存和配置激活影响数据状态。
- [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter)：DWG/DXF 文件格式转换。转换和制造语义识别是两个步骤。
- [ezdxf 官方说明](https://ezdxf.readthedocs.io/en/stable/)：DXF 读取库的范围，DWG 通过 ODA 接口处理。本版使用项目自己的有限 DXF 读取器，不声称已经集成完整 ezdxf。
- [黑湖科技官网](https://www.blacklake.cn/)：竞争能力核查依据。公开营销介绍不是本项目或竞品的独立基准测试。
