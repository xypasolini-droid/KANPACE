- `/control/index.html` 为中台：管理员登录/首次设置、开通独立工厂、编辑工序与串并行、配置对象与功能、保存草稿、预览各工种任务、人工复核后启用并显示回执。

## 实际业务数据核对

`work/product-platform-20260907/baseline.json` 和 `after.json` 比较实际数据库记录内容哈希。13 项目、652 构件、16 任务、8 人员、17 文件以及既有工厂/流程模板记录均无变化。

本地新入口、脚本、workspace 与 health 接口返回 HTTP200。客户配置操作未在真实工作台执行；首次中台管理员由使用者在本机页面设置。

## 仍保留的产品边界

参考起点为展柜、机械设备装配和工程现场；配置可修改实际工序，但不会自动证明适用于调研中的全部产业。每个工作对象采用同一完整路线；跨对象装配汇合及流程行业批次配方需要独立实现。

原生 MAX / SolidWorks 文件并未新增原生解析。项目三维展示选真实支持格式的整体文件，制造仍以确认工程图、BOM 和人工复核为依据。独立工厂是同机应用/存储隔离，不是对操作系统管理员的隔离。
