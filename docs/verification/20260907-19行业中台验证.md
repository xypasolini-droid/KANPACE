## 浏览器实际验证

- 正式服务只读：公开行业目录实际显示 19 项，行业和产业类型筛选、具体生产类型、资料要求、对象字段、串并行、来源均可浏览。最终展示地址：`http://127.0.0.1:8765/control/index.html?industry=rattan`。
- 临时工厂：登录 → 藤铁/木作 → 保存 → 7 道工序预览 → 启用 V1；切换食品/饮料 → 保存 → 7 道工序预览 → 启用 V2。浏览其他行业和取消替换均保留尚未保存的本厂表单。
- 工厂端：创建明确归属临时工厂的饮料订单，填写产品规格、工艺版次 QA-R1、数量 1 批、计划重量 12.5 kg；生成并复核 7 道行业任务。
- 工艺单经真实 HTTP 上传到临时库，未按展柜 BOM 解析。随后在浏览器关联文件 → 重建无实绩草稿 → 工作包复核 → 文件版本核验 → 确认发布。任务实际变为当前 R2 的待开工状态，计量显示“批”，工时保持待核对。
- 文件核验曾因前端误用 `document_id` 而阻断，已改为后端实际 `document_ids` 数组；测试夹具改用实际 `operations.validate_objects` 输出，并通过同一浏览器流程复验。
- 工作包摘要直接显示 QA-R1、12.5 kg、关联文件名；食品页面显示真实岗位，不再显示木工默认覆盖。
- 中台 1280、900、390 像素无横向溢出；键盘 Enter 可选择行业。临时浏览器和服务已清理。
