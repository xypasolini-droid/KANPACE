## 验收范围

- 资料导入去掉独立工程模型入口，成本报价移至经营管理；排程步骤收拢为生产排程表、物料需求与采购。
- 排程 Excel 生成可保存的工序建议、参考周期与订单顺序。工艺前序经过核对后执行；原工程前序保留。未知周期不写成零，日期统计不当成确定的工艺因果。
- 新 Excel 按完整订单号核对选定覆盖范围；保护完工记录、未勾选记录与手工修改；真实计划使用版本校验与事务，冲突不能留下半份排程。
- 整单派工按工人和胸牌一对一绑定；待派任务使用当前排程顺序，任务回执与图片回执分别记录。停止后续派发保留原生产进度与已接收任务。
- 拆单净需求核对库存后生成采购草稿。库存未知与库存零分开；可用库存按交期分配，多个订单不重复占用；不扣减库存、不向供应商下单。
- Web 图册保留项目/任务范围，支持多图、两图核对；新固件支持同任务六张图，使用真实图源，不推测效果图中的制造尺寸。
