# KANPACE 软件端与智能胸牌端流程图

以下按当前代码可执行的流程绘制。软件端包含一次性的中台开厂配置和每个订单重复执行的工厂流程；硬件端按仓库中的 ESP32-C3 固件源码绘制。效果图用于看项目整体，施工图、工程图和 STEP 模型用于提出并核对构件候选；候选不是可直接下料的 BOM。

## 软件端：从建厂到订单发货

```mermaid
flowchart TB
    C["中台开厂配置（一次）<br/>选择行业模板，核定本厂岗位、工序和权限"] -.-> A
    A["接单建项目<br/>导入订单、效果图、施工图／工程图、STEP 与 Excel 排程表"] --> B["看图拆单<br/>效果图看整体；OCR／STEP 生成有来源的构件线索"]
    B --> V{"技术员已核对<br/>数量、材料、加工尺寸？"}
    V -- 否 --> B
    V -- 是 --> D["生成工种任务并复核<br/>发布当前工程版本"]
    D --> E["备料与排程<br/>核库存和采购草稿；调整工序先后、人员与日期"]
    E --> F["按项目派工<br/>工人与胸牌绑定，登记领取并下发任务"]
    F --> G{"胸牌返回收件回执？"}
    G -- 否：检查连接、重试 --> F
    G -- 是：仅表示收到 --> H["现场执行<br/>工人看图、开工、报进度与完工"]
    H --> X{"缺料、异常或插单？"}
    X -- 是 --> Y["暂停并记录原因<br/>Web 处理缺料、异常或插单"]
    Y --> Y2{"恢复原任务？"}
    Y2 -- 是 --> H
    Y2 -- 否：调序或改派 --> E
    X -- 否 --> K["核对工序完工数量"]
    K --> L["逐件确认二维码标签<br/>按需登记货位"]
    K --> Q["按要求质检与验收"]
    Q -- 返工 --> H
    L --> Z{"贴标、质量和交付条件已核对？"}
    Q -- 验收通过 --> Z
    Z -- 否 --> H
    Z -- 是 --> M["项目完成、发货并留档<br/>退出待派工列表"]
    L --> R["当日任务和标签核对后<br/>登记实物胸牌归还"]
```

软件图中，收件回执与开工记录分开；工序完工、贴标确认、质检和发货也分别记录。新版本图纸会使旧工程依据失效，需重新复核。物料环节目前生成可审核的采购草稿，并不自动向供应商下单。项目关闭前会核对未完任务与质量问题；不把图上的正常主线误认为唯一合法关闭方式。

## 硬件端：工人拿到胸牌之后

```mermaid
flowchart TB
    A["开机<br/>恢复最近任务和待同步事件"] --> B{"连接方式"}
    B -- USB --> C["USB 身份握手"]
    B -- 已配置的 2.4 GHz Wi‑Fi --> D["连接工厂局域网"]
    C --> E["等待 Web 派工"]
    D --> E
    E --> F["校验任务身份与版本<br/>保存当前任务"]
    F --> G["回传收件 ACK<br/>只表示任务已收到"]
    G --> H["任务首页<br/>大字工种、部件、工序、数量与施工图缩略"]
    H --> I["按需查看施工图／效果图<br/>放大移动、查看要点"]
    I --> H
    H --> J["触屏确认开工<br/>事件先写入本地待同步记录"]
    J --> U{"收到 USB 业务 ACK？"}
    U -- 否 --> W["保留事件并等待重试<br/>不提前改生产状态"]
    W --> U
    U -- 是 --> N["任务进行中"]
    N --> O{"现场发生什么？"}
    O -- 缺料／质量／设备／插单／其他 --> P["选择原因并确认暂停<br/>事件经 USB ACK 后生效"]
    P --> T["Web 负责人处理<br/>缺料、异常或排程变化"]
    T --> T2{"恢复原任务？"}
    T2 -- 是 --> T3["胸牌确认恢复<br/>USB 业务 ACK 后继续"]
    T3 --> N
    T2 -- 否：改派 --> E
    O -- 全部数量完成 --> S{"该工序需要 Web 验收？"}
    S -- 是 --> Q["在 Web 完成要求的验收"]
    S -- 否 --> V["触屏确认完工<br/>USB 业务 ACK 后更新状态"]
    Q --> V
    V --> L{"有待确认的工件标签？"}
    L -- 有 --> M["看标签短码<br/>人工核对实物并贴标"]
    M --> R["触屏确认贴标<br/>USB ACK 更新记录"]
    L -- 无 --> Z["等待或领取下一任务"]
    R --> Z
    Z --> AA{"当日任务与标签均完成<br/>且最新回执允许归还？"}
    AA -- 否 --> E
    AA -- 是 --> AB["提示归还胸牌<br/>Web 登记已收到实物"]
```

当前 Wi‑Fi 能接收任务；图像传输、开工／暂停／恢复／完工和贴标业务回执走 USB。胸牌只缓存最近一项任务，不是整日离线任务队列。图册最多保留六张 JPEG。硬件外观概念中的摄像头扫码、拍照录像、AI 质检、旋钮和橙色侧键没有画入已实现流程。

## 两端交接点

| 交接 | 软件端记录 | 胸牌端显示或操作 |
| --- | --- | --- |
| 派工 | 当前工程版本、任务、人员与胸牌绑定；记录设备收件回执 | 收到并保存当前任务，显示大字任务与图册 |
| 开工与异常 | 按业务事件更新进度；缺料／插单由管理者处理排程 | 工人确认开工，选原因暂停，等待同步确认 |
| 完工与标签 | 单独记录工序完工、质检与每件标签确认 | 工人确认数量、核对标签短码并贴实物 |
| 归还 | 检查领取任务与标签后登记实物归还 | 最新回执允许时提示归还胸牌 |

实现依据：[每日工作协议](../DAILY-WORKFLOW-R32.md)、[真实自动拆图算法](../engineering/真实自动拆图算法.md)、`static/daily-workflow.js`、`kanpace/application/project_dispatch.py`、`firmware/goldenmorning-display/src/cabinet_badge.h` 与 `firmware/goldenmorning-display/src/cabinet_execution.h`。固件图反映仓库中的 1.6.1 源码与主机测试；本版尚无实板刷机验证记录。
