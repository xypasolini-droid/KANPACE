# 泉州产业业务链：装备、石材、卫浴、电子

核验日期：2026-09-07。用途：为 KANPACE 的行业选择、工厂初始化和流程配置提供依据，不是企业现场实施方案。已阅读用户提供的《泉州产业调研2607_V2.html》，其中企业与产业分类作为检索线索；以下事实独立核验于企业披露、企业官网和政府网站。未使用集群产值估算市场容量，未联系企业、读取企业内部系统或上传客户文件。

**产品判断：适合复用的是“工程版本—物料—工序—人员/设备—质量—交付”的数据骨架，不能复用一条固定展柜生产线。** 以下“建议业务链”“输入资料”“配置对象”均为行业通用建模推演，需用目标工厂的一张真实订单、工艺卡和完工记录确认；不是声称列名企业逐项使用这些文件或工序。公开报道有既有 PLM/MES 时，优先从其已发布数据接任务、回传进度，不能另造相冲突的主档。

## 1. 机械装备：以单台设备和部套齐套为中心

**直接证据。** 铁拓机械2025年ESG报告第19–20页披露：其PLM管理设计资料，图纸按工序、班组存储并动态送到车间终端；三维模型和工艺参数服务切割、焊接、装配、质检，车间图纸异常可反馈设计。证明“资料与岗位任务关联”是当地真实需求，也表明成熟工厂可能已经有PLM。[铁拓机械2025年ESG报告](https://static.cninfo.com.cn/finalpage/2026-04-14/1225102146.PDF)

**建议输入。** 客户技术协议/订单配置、发布的装配BOM和零件图、SLDASM/SLDPRT完整引用包、STEP派生模型、焊接/加工图PDF或DWG/DXF、电气原理图/接线表、采购清单、检验规范。STEP几何不能代替材料、焊缝、配合、公差和采购件型号；效果图只解释整体样子。

**建议业务链。** 技术确认→发布部套BOM后分支：①结构件备料→切割/成形→组焊→加工/表面处理；②机加工件毛坯→加工→检验；③电机/轴承/气液压等采购件→到货检验；④电柜/线束备料→装配接线。按部套齐套汇合→机械/电气总装→调试→验收→分件包装/运输→现场安装交付。热处理、精加工、喷涂等可按本厂能力设为外协节点，不能默认所有企业都外协或固定同一加工先后。

**关键对象。** 设备项目号、设备序列号、部套/零件号及版本、单件/批次数量、采购到货、工序检验、外协发出与回厂、设计变更影响范围。并行分支按部套和需求数量汇合；不能只检查“几个工种都点了完成”。

**KANPACE切入。** 工程资料发布后，自动核对BOM/图号对应，形成工种图文包；把缺件、外协延期、返工和装配条件呈现给主管；保留PLM/ERP编号及版本。先覆盖部套交接、装配齐套和现场反馈。不承诺由任意STEP自动还原原生参数树、焊接工艺或完整制造BOM。

## 2. 石材加工与石雕：至少拆成两种模板

**直接证据。** 南安市公开文件附录E.3描述石材数字化方案：给每片工程板建立身份，关联进厂、扫描、数字排版、切割、车间流转、包装和出厂。它支持“板材实物—图像—排版—成品位置”追踪，不能把同花色两片天然石材视为可任意互换。[南安市公开石材加工文件，附录E.3](https://nanan.gov.cn/zwgk/zfxxgkzl/zfxxgkml/hjbhggwsaqscspypcpzldjdjcqk/202309/P020230928420368419553.pdf)

惠安官方记录显示当地已有雕刻机器人应用，传统石雕产品又包括建筑构件、园林雕塑和工艺品；这不是同一套大板矩形排料业务。[惠安石雕](https://cbtb.quanzhou.gov.cn/lyfw/mjms/201607/t20160711_1906162.htm)；[惠安石雕机器代工应用场景调研](https://www.huian.gov.cn/zwgk/xwzx/haxw/202409/t20240929_3086135.htm)

| 项目 | 工程板/台面加工：建模建议 | 石雕/异形构件：建模建议 |
|---|---|---|
| 输入工程资料 | 现场尺寸、施工/安装图、加工单、DXF轮廓、边型/开孔明细、真实大板扫描图、排版批准记录 | 艺术确认稿、泥稿/扫描模型/三维网格、尺寸和分块图、安装锚固图、材料要求、CAM工艺文件 |
| 典型业务链 | 量尺/深化→大板选料和扫描→纹理/缺陷约束排版→切割→磨边/开孔/异形加工→试拼/修整→位置编号→成套包装→安装 | 造型确认→选石/分块→开荒粗加工→机器或手工雕刻→手工修饰→表面处理→试拼/验收→包装→现场安装 |
| 并行和汇合 | 同安装区域多块板并行加工；以房间/立面/台面的一套板及包装箱汇合；补板必须关联原位置 | 多分块并行雕刻，底座/金属锚固件可另行备制；按作品、连接界面及安装顺序汇合 |
| 外协候选 | 水刀、异形加工、特殊表面处理、物流安装；需记录板身份和收发损耗 | 专门雕刻、特殊表面、金属配件、吊装；需记录承制人和批准样式 |
| 核心追溯 | 荒料/大板ID→扫描图→切割版→成品板ID→建筑安装位置；余料、裂纹、色差/纹理方向及替换记录 | 作品/分块ID、造型版次、加工模型、师傅、修样、安装锚固、验收批准 |
| KANPACE入口 | 已确认加工单→板件任务、扫码流转、缺板/补板、箱单和安装图；排料需增加纹理、缺陷、刀具工艺约束 | 按作品/分块分工、模型与施工图同步、工时和修样反馈、交接验收 |

**不可混用。** 现有通用矩形套料不能直接宣称“石材智能排版”，因为真实大板边界、裂纹、纹理连续、对花和安装位置可能比面积利用率更重要。雕塑网格可以表示造型，但不能单独推导锚固安全、刀路、手工工时和安装工艺；不同自然材料的余料也不能只按SKU数量合并。

## 3. 水暖厨卫：五金、陶瓷、智能总装分别建路由

**直接证据。** 泉州市政府2026-02-23介绍南安产业链覆盖铸造、电镀、五金、管件和卫浴制品，并有专业配套园区。2021年的石狮九牧产业园报道明确列出拟建的铸造、机加、抛光、总装和电镀生产线；该历史资料只能证明当时规划，不能当作当前设备清单。永春九牧数字陶瓷工厂的政府报道另列球磨、成型、干燥、视觉检查、施釉与搬运，说明陶瓷和金属是不同制造分支。[南安水暖厨卫产业链](https://www.quanzhou.gov.cn/zfb/xxgk/zfxxgkzl/qzdt/qzyw/202602/t20260223_3268744.htm)；[石狮重点项目报道](https://www.quanzhou.gov.cn/zfb/xxgk/zfxxgkzl/qzdt/xsqdt/202108/t20210818_2606023.htm)；[九牧数字陶瓷工厂报道](https://www.quanzhou.gov.cn/zfb/xxgk/zfxxgkzl/qzdt/qzyw/202107/t20210713_2586972.htm)

**建议输入。** 产品规格、批准BOM、零件/装配模型和制造图、模具号、材料/镀层要求、颜色样板、检验规范；陶瓷增加泥釉配方和模具/烧成要求；智能产品增加电子BOM、线束/接线图、固件和功能测试版本。工程客户的场景效果图与批量制造的产品图需独立关联。

**建议业务链。** 五金：铜材/坯件→铸造或采购坯件→机加工→抛光→电镀/其他表面→检验；陶瓷：原料/泥釉→成型→干燥/修坯→施釉→烧成→分级检验（具体顺序随工艺确认）；塑件、密封、阀芯、电子控制板等另行自制或采购。合格件按产品BOM齐套→装配→密封/功能等检验→包装。智能坐便器还需将陶瓷体、盖板、水路、电控及固件/测试结果关联到成品。

**关键对象。** SKU及规格配置、模具/穴位、炉次或原料批次、表面处理批次、色号、外协批次、合格/返工/报废数量、关键部件批号、成品序列号或批号。电镀外协按批收发可拆分回厂；烧成按窑次/装载组织，不能按单个工人任务时长直接排窑。

**KANPACE切入。** 面向中小配套厂，先把加工单→外协→回厂检验→装配齐套打通；缺件/漏镀/色差/返工单直接回原批次和供方。保留已有ERP库存、QMS检验规则，不把图纸OCR分数当作合格判定。展示工牌用于人员作业确认和交接，不能代替炉温、电镀参数、自动测试等设备过程记录。

## 4. 电子装配与半导体：必须分开产品边界

**直接证据。** 科立讯官网确认其泉州制造设施；政府历史报道具体提到其SMT车间。科立讯2025-06-20发布IMS-WMES二期启动消息，目标包括生产数据贯通和数字质量管理；这是项目启动事实，不等于所有目标均已验收。[科立讯公司介绍](https://kirisun.com/about)；[泉州政府SMT车间报道](https://www.quanzhou.gov.cn/zfb/xxgk/zfxxgkzl/qzdt/qzyw/201701/t20170117_418689.htm)；[科立讯IMS-WMES二期启动](https://www.kirisun.com/kirisun-launches-phase-II-of-IMS-WMES-project)

三安光电2025年报第11–12页区分外延片、芯片和应用产品，生产按订单、预测及库存组织；此处是**集团业务事实**，本次没有逐项确认泉州某厂的具体晶圆工艺、设备接口、工时和配方，不将集团所有产线归到泉州。[三安光电2025年报](https://dataclouds.cninfo.com.cn/shgonggao/hsomarket/2026/20260424/2f694359de584ba0b9266049bc382b7a.PDF)

| 项目 | 电子整机/PCBA装配：建模建议 | 半导体晶圆/器件制造：边界模型，待专项访谈 |
|---|---|---|
| 输入资料 | 发布电子BOM、原理图、PCB制造包/Gerber或ODB++、贴装坐标、装配图、作业指导、固件及测试程序版本 | 经授权的产品/批次规格、工艺流程与配方版本、掩模/设计数据标识、设备/量测记录、晶圆图；不得仅凭GDSII或STEP推导全工艺 |
| 典型链路 | 来料/备料→锡膏印刷→贴装→回流→检查/测试→后焊/返修；外壳/线束/显示等并行备制→整机组装→烧录/功能或老化测试→包装 | 依器件分为衬底/外延、晶圆加工、测试、切割、封装及终测等产业环节；每厂只做其中一段或数段。晶圆加工可能反复经过相同设备族，不能视为一次性直线装配 |
| 关键追溯 | PCB/PCBA批次或序列号、元器件料卷及批次、替代料批准、站点、固件、测试限值版本、返修前后记录、成品序列号 | 晶圆批/片/位置、批次拆分合并、设备及腔体、配方/量测版本、工艺等待限制、良率与缺陷；具体字段由原MES和工艺部门确定 |
| 并行/外协 | PCB制板、SMT或外壳可能外协；装配前按批准BOM、版次和物料批次齐套；返修后重测 | 外延、晶圆、封装、测试可能跨公司分工；回厂判定需质量和工艺规则，不能只有“外协已收货” |
| KANPACE适合入口 | 小批试制、手工作业、齐套/缺料、返修、外协收发、工程变更到工位；与既有WMES/QMS交换任务和结果 | 优先设备维护、备件、厂务、工程安装、异常协同、只读汇总；核心晶圆MES/设备自动化需独立产品和验证计划 |

**不可混用。** 电子装配的零件贴装、整机装配与半导体前道制造不是同一个行业流程。现有CAD几何/OCR/排程引擎都不等于电子设计审查、贴片机编程、晶圆工艺优化或SECS/GEM设备控制；公开资料也不构成API已开放的证据。

## 5. 给配置中台的最小行业差异

| 配置维度 | 机械设备 | 石材/石雕 | 卫浴 | 电子装配 | 半导体外围协同 |
|---|---|---|---|---|---|
| 工作对象 | 设备→部套→零件 | 大板→成品板→安装位置；作品→分块 | 产品→零件/模具→批次 | 产品→PCBA/整机→序列号 | 工程/设备→作业；不改晶圆主档 |
| 主要汇合规则 | 部套齐套+工序检验 | 同区域/作品的板块完整、纹理/位置正确 | 批次合格件齐套、颜色/版次一致 | BOM/硬件/固件版本及关键料一致 | 按原系统放行条件 |
| 关键计量 | 台、套、件 | 片、块、㎡、m³、件分开管理 | 件、套、批、炉/窑次 | 件、板、批、序列号 | 工单/备件/设备；片与批仅映射 |
| 产能约束 | 机台、工装、技工、装配场地 | 大板可用区域、机台、师傅、安装组 | 模具、加工/表面线、批炉、检验 | 线体、换线、测试工装、人员 | 维护窗口、资质、作业审批 |

**首次见老板只收六包资料。** ①一张近期真实订单和交期；②配套图纸/模型、已用BOM或加工单；③实际工序/部门及内外协；④人员设备和班次；⑤库存/缺料与排程Excel；⑥一张完工、返工或质检记录。先确认工厂实际制造的产品和工序边界，再生成待确认模板。并非有一份效果图即可可靠生成整厂排产。

共享模板只含字段、一般工序及检验结构；客户图纸、价格、配方、产能、供应商、工时和训练/检索资料留在本厂空间。通用模板复制不能复制另一工厂的订单实例或工程资产。每个自动建议应显示依据资料和版本，关键制造放行由本厂指定角色确认。
