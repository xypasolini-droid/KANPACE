# 五项引擎安装入口

在 `outputs/cabinet-flow` 项目目录执行。统一入口复用三个已有安装器，各组依赖继续位于独立环境，主服务仍使用自己的 Python 环境。

```sh
# 只检查已安装的五项引擎，不安装、不打开业务数据库
python3 tools/setup_intelligence.py --check

# 首次安装全部五项，使用已安装的 Python 3.11
python3 tools/setup_intelligence.py --python 3.12

# 按需安装一组；也支持 --python 3.12 或解释器完整路径
python3 tools/setup_intelligence.py --only engineering --python 3.12
python3 tools/setup_intelligence.py --only optimization --python /opt/homebrew/bin/python3.11
python3 tools/setup_intelligence.py --only agent --python 3.12

# 只检查指定组
python3 tools/setup_intelligence.py --check --only optimization
```

`--only` 可取 `engineering`、`optimization`、`agent`、`all`，默认 `all`。完整安装或工程组需要 Python 3.12；仅优化/助手组可选 Python 3.11 或 3.12。工程安装器需要 `uv`，优化安装器需要 Git 和本机 C++ 编译工具链（macOS 可使用 Xcode Command Line Tools）。原生软件、Python 依赖和 OCR 模型首次安装需要联网下载；安装后这五项引擎的业务处理在本地完成。统一入口不会下载或配置通用大语言模型。

| 安装组 | 实际引擎 | 安装器 | 独立环境 |
|---|---|---|---|
| engineering | PaddleOCR、Open CASCADE（通过 cadquery-ocp） | `tools/setup_engineering.py` | `.venv-engineering`，模型位于 `models/engineering` |
| optimization | Google OR-Tools、PackingSolver | `setup_optimization.py` | `.venv-optimization`，原生 CLI 位于 `bin/optimization` |
| agent | LangGraph | `tools/setup_agent.py` | `.venv-agent` |

`--python` 会解析为真实解释器路径。工程和优化安装器收到 `--python <路径>`；工作流安装器没有此参数，统一入口使用该解释器启动它，供其创建独立环境。已有环境由原安装器复用，`--python` 不会迁移或删除已有环境；如需切换现有环境的 Python 版本，应先单独安排环境重建。`--check` 检查的是已有引擎环境，因此不使用 `--python`。

检查结果以 JSON 输出到标准输出，检查进度输出到标准错误。`engines` 列出所选引擎的 `available`、版本及探测结果；`all_available` 只针对本次所选组。退出码 `0` 表示所选引擎全部可用，任一关键引擎不可用或安装失败返回非 `0`。安装依次执行，遇到安装失败会立即停止；成功安装后自动检查所选组。

工程检查在临时空目录中创建探测目录，真实导入本地依赖并检查 OCR 模型文件，结束后清理临时目录。OR-Tools 执行一个空 CP-SAT 模型；PackingSolver 对一块合成测试板真实求解并独立验证布局；LangGraph 导入工作流和 SQLite checkpoint 依赖。整个检查不创建 `Store`、不读取客户图纸、不创建工厂分析记录，也不写业务数据库。这些是安装健康检查，客户真实图纸的识别准确率和真实工单的排程效果仍通过项目验收验证。

详细版本、许可证和各组复现限制见 [优化引擎接口与复现](../optimization/引擎接口与复现.md) 与 [LangGraph 实际接入与复现](LangGraph-实际接入与复现.md)，以及各组 `licenses` 目录。

工程组的完整依赖锁已在 Python 3.12 验证，需要 3.12；`--only optimization` 和 `--only agent` 可使用 3.11 或 3.12。默认全部安装时请明确传入 3.12 路径。
