# KANPACE 五项核心引擎使用说明

这五项能力接在现有项目、构件复核、排程和报价流程中。工厂管理者使用中文按钮，不需要操作开源项目的命令行。

## 在哪里使用

| 能力 | 网页入口 | 本次接入的实际功能 |
|---|---|---|
| PaddleOCR | 项目 → 图纸与拆单 → 施工图与工程模型 → 识别图纸 | 对图片或指定 PDF 页面做本地文字识别，原图与文字并排显示；勾选文字高亮原图位置，带依据建立待复核构件。 |
| Open CASCADE | 同一处 → 核对模型，或“识别图纸 / 核对模型”选择 STEP | 读取真实 STEP 实体与装配结构，核对实例数量、独立定义、单位、表面积、体积、外包尺寸和几何有效性。 |
| Google OR-Tools | 生产 → 产能与插单 → 优化排程 | 按现有人员、工作中心、工作日历、工时、已冻结占用、物料与前后序生成排程预览；显示原顺序方案与优化方案差异，确认后采用。 |
| LangGraph | 左侧“操作助手” → 分析延期原因并比较排程 | 分步读取登记依据、分析风险、等待用户继续、计算两个候选、生成预览；确认采用走现有排程接口。关闭后可继续之前的工作流。 |
| PackingSolver | 项目 → 成本报价 → 板材排料 | 输入确认过的矩形下料清单，考虑材质、厚度、纹理、原板、锯缝、裁边和数量，输出每张板的排料图、利用率、原板金额与毫米单位切割树 CSV。 |

开源选型页上方增加五项本机状态检查。其余候选目录继续作为研究资料，不能把候选项目当成已经交付的功能。

## 从施工图到任务

1. 打开具体项目，上传施工图或 STEP。已关联的原施工图页缓存也可以选择，保留原文件名和原页码。
2. 点击“识别图纸”。PDF 填入页码，例如 `2,3,5`，单次最多 12 页；图片直接识别。
3. 在结果中勾选原文，原图会高亮相应位置。点击“用选中文字建构件”。
4. 技术员填写或核对构件名称、材质、尺寸、数量与做法，保存为待复核构件。原图坐标、来源摘要和处理记录一并保存；再次打开构件，可点击“查看识别依据”回看相同原图与高亮。
5. 按已有流程复核构件、生成工序、确认发布、分配人员。识别本身不会审批构件或下发工牌任务。

处理任务保存在本厂目录。关闭识别窗口不会丢失后台任务，可以从“处理记录”重新打开。来源被替换、移除或标记为旧版本后，历史识别不能直接作为新构件依据，需要重做识别。

## 排产和暂停插单

已确认的工时和人员是计算基础。未核定工时、缺少负责人或缺少齐套信息的任务会列出未排原因；求解器不会猜出缺失数据。已有有效计划保留占用，正在执行和暂停任务的实际状态不会因为试算而改变。

在“产能与插单”勾选任务，按需要指定优先插入、加工、换型、等待时间，生成预览。审查开始时间、加工结束、可转序时间与超交期任务，再填写采用说明并确认。计算期间资料发生变化，旧方案不能直接采用，必须重新试算。

助手的“继续比较”只生成建议。最后的采用操作仍需要管理者确认；账户权限、工作流所属人、工厂和项目范围都会检查。

## 排料结果如何看

同一材质、厚度与纹理要求单独计算一组。填写加工所需的下料尺寸，不直接使用成品外形尺寸或未展开钣金尺寸。纹理方向有要求时禁止旋转；锯缝与每边裁边以毫米填写。

结果包含原板数量、每块零件的实际布局和剩余区域。每张原板单价未填写时，不显示虚构金额；原方案用板数量未填写时，不声称节省了几张板。报价中的人工、税费、外协和余料价值仍由原业务流程核算。

“下载切割树 CSV”以毫米输出，以原板左下角为坐标原点，包含父子板关系。原生算法内部的百分之一毫米坐标已转换，根节点标记为板内有效区。该文件供工艺人员复核，不是可直接执行的机床程序。

## 本次能力边界

- OCR 识别分数不是制造尺寸正确率。当前接入文字识别和位置证据，没有承诺自动理解所有尺寸链、公差、材料表或自动完整拆单。
- 本机使用 PaddleOCR 3.3.2 / PaddlePaddle 3.2.2 和经固定版本、校验摘要的 PP-OCRv5_mobile_det / PP-OCRv5_mobile_rec 轻量检测与识别模型。选择的是实际兼容并验收的运行组合，不能把前期研究中的其他模型版本当成本机运行版本。
- OCCT 核对 STEP/STP；原生 SolidWorks 文件需由装有 SolidWorks 的 Windows 桥接导出 STEP。当前不解析 PMI、不自动确定材料密度和重量，不把外包尺寸当成下料尺寸。
- OR-Tools 只对输入的制造约束和目标求解；可行解与最优解分别标记。合成样例的改善不代表客户每个订单都能获得相同比例的改善。
- LangGraph 已接入真实的确定性多步骤工作流。默认没有安装通用大模型，也不使用云端模型；可选本机模型接口仅整理统计，不能改事实或调度工具。
- PackingSolver 本次接入矩形板材的齐头切排料，不包括异形套料、板件封边扣尺、钣金展开或 CNC 后处理。

## 工厂资料和部署

工程输入副本、识别结果、原图页、排料方案、助手检查点均归当前工厂。不同工厂不能通过这些接口引用对方的处理记录。公开模型与运行库可共用，客户工程资料不用于其他工厂。本地操作系统管理员的磁盘权限仍需要由实际部署管理。

首次安装仅下载公开依赖与模型。正常处理使用本地计算；未开启任何客户图纸云端上传。各引擎放在独立环境，不把大型原生依赖装进现有 Web 环境。

运行状态和重装命令见 [五项引擎安装入口](五项引擎安装入口.md)。详细技术文档见 [本地工程引擎](../engineering-engines.md)、[优化接口与复现](../optimization/引擎接口与复现.md)、[LangGraph 实际接入](LangGraph-实际接入与复现.md)。许可证、版本锁和模型摘要已随代码保留；本次完成的是本机接入。对外分发原生运行环境时，还需补齐随包库的对应源码、构建材料和适用的替换或重新链接安排；不能把 OCCT 的 LGPL 加例外许可标成无条件 MIT/Apache。
