# 暂停、换单与急单现场操作

适用：柜序 Web 的「工种任务」页面。先选择正确项目，再打开任务卡片。任务必须已经发布、分配给具备技能的负责人，且前置工序完成，才能点击「开始工序」。同一负责人同一时间只执行一项任务。

**始终填写累计完成的整件数。** 例如任务总量 10 件，已经做好 3 件，第 4 件加工到一半，应记录“累计已完成整件数：3”，交接说明写“第 4 件开槽中，半成品放 A 架，夹具保持原位”。剩余仍为 7 件。不要填写 3.5，也不要每次把本次新增件数当累计数。

1. **只保存进度，继续做当前任务。** 打开进行中的任务，点击「记录部分进度」，填写累计整件数和进度说明，再点「保存累计进度」。这不会结束工序。即使已做数量等于总量，也还需人工确认整项完工。

2. **缺料或遇到问题，先暂停。** 点击「暂停 / 交接」，在「暂停分类」选择「缺材料」「质量问题」「设备问题」「急单插队」或「其他原因」。核对累计完成数，填写「暂停原因」和「交接说明」，点击「保存暂停与交接」。任务进入「暂停待恢复」，原总量、已做数量和历史记录保留。随后可打开满足开工条件的其他任务，点击「开始工序」。

3. **把急单排到前面。** 打开急单任务，点击「调整优先级」，选择「优先」「加急」或「特急」，填写调整依据，点击「保存优先级」。任务看板各列按优先级从高到低排列，可用「加急 / 特急」筛选查找。这个操作只调整顺序，不会启动急单，也不会暂停当前任务；前置工序仍须完成。

4. **立即暂停当前任务，换做指定急单。** 回到正在执行的原任务，点击「暂停并换做」。填写原任务的暂停分类、累计完成数、暂停原因和现场交接，再在「换做任务」中选择目标。可以选择同一负责人在其他项目中的任务；跨工种时此人必须具备目标技能。目标选择项会显示优先级与项目；不满足条件的目标不可选择，可展开「查看不可切换的任务与原因」。确认后点击「保存交接并切换」。系统把“原任务暂停”和“目标开工”一起保存：若目标校验失败，本次填入的进度、暂停与切换都不保存，原有已保存记录不受影响。

5. **目标本来也是暂停任务时，补充解除依据。** 选中这类目标后，会显示「目标任务解除暂停依据」。须写明为什么现在可以继续，例如“材料已到货，型号与批次核对通过”。原任务的暂停说明与目标任务的解除依据分别保存，不能用“急单”代替缺料、设备或质量问题已解除的确认。

6. **急单做完，回到原任务继续。** 在急单任务点「提交完工」，核对全部数量和验收要求，填写适用的完工/检验记录，勾选「已核对全部数量与本工序验收要求」，再点「确认整项完工」。然后切回原项目，用「暂停待恢复」筛选找到原任务，点击「恢复原任务」，填写「解除暂停依据」，核对或补充交接说明，点击「恢复并继续原任务」。原来完成 3/10 件，恢复后仍是 3/10，继续剩余 7 件。若急单本身还没有做完，应先对它暂停或切换，不能把它提前记为完工。

7. **把最新任务状态显式同步到工牌。** 保存进度、暂停、换单或恢复之后，Web 不会自动下发。打开要显示的任务，点击「发送到工牌」，核对发送预览，再点预览中的「发送到工牌」。USB 或 Wi-Fi 连接须已通过固件握手；等到页面出现「设备已接收」才表示匹配任务和版本的回执已收到。回执只证明工牌收件，不表示生产允许开工、实际开工或已经完工。任务完工后不能再派发该完成任务；工牌可能仍显示上一任务，应选择下一任务再下发。当前不通过工牌物理按键提交生产报工。

看到「未记录」「待核对」时，说明旧任务没有逐件进度记录，不能据此认定已经做了 0 件。首次用「记录部分进度」时，应先核实现场累计整件数；如果还没有任何整件完成，可以明确填 0 并描述半成品。暂停或切换时，数量输入可留空以保留未记录状态，交接说明仍必须填写。

出现“任务已被其他操作更新”时，当前输入会保留，先点击「重新载入任务」，核对最新数量和状态后再提交。若提示“业务状态已保存，但最新视图读取失败”，本次操作已经保存，不要重复提交；重新载入后查看结果。材料补齐、技能匹配或目标优先级提高，都不会取消版本发布和工序依赖检查。

任务弹窗的「最近执行记录」可查看近期操作；完整任务与事件可通过工程 JSON 导出保留。当前任务清单 CSV 也包含已做、剩余、优先级、暂停原因和交接说明。未保存的弹窗内容不会自动写入；已经保存的内容在服务重启后仍然存在。
