# 真实订单拆单草稿接口

`POST /api/order-drafts/import` 导入已从图纸 / 表格提取、带定位依据的订单草稿。接口不解析原生 CAD 几何，不读取 `source_path` 指向的文件，也不复制这些原始文件。

```json
{
  "order_key": "DEMO-ORDER-001",
  "source_revision": "07.31 施工图",
  "project": {"name": "合成展示柜订单", "client": "客户名称", "due_date": "2026-07-31", "quantity": null},
  "version_note": "版本选择与改单核对说明",
  "sources": [{"source_path": "<由所属工厂填写原文件>", "filename": "施工图.pdf", "kind": "施工图", "pages": 8, "note": "用于规格核对"}],
  "issues": ["订单层级待核对事项"],
  "parts": [{
    "id": "A01", "name": "墙柜 A", "item_level": "assembly",
    "material": "木作柜体与金属边框", "category": "", "finish": "待确认",
    "quantity": null, "quantity_unit": "台", "quantity_basis": "整单数量待核对",
    "specification": "1200×400×2400",
    "overall_dimensions": {"length_mm": 1200, "width_mm": 400, "height_mm": 2400},
    "source_file": "施工图.pdf", "source_reference": "第 2 页 A01",
    "evidence": [{"source_path": "<由所属工厂填写原文件>", "page": 2, "quote": "墙柜 A 1200×400×2400"}],
    "review_questions": ["缺少板件厚度与内部结构尺寸"],
    "work_scopes": [{"trade": "木工", "title": "拆分柜体结构与板件", "basis": "施工图标明木作柜体"}]
  }]
}
```

- 同一 `order_key + source_revision` 对应一个项目；相同规范化内容返回 `duplicate: true`，保留项目 / 部件 ID。同版本内容变化会更新同名草稿文档，旧文档与旧部件留存为历史。不同来源版本建立独立项目，避免把改单与原单合计。
- `item_level`：`assembly` 柜体 / 总成、`component` 零件 / 组件、`material` 材料 / 配件、`unknown` 层级未确认。
- 柜体外形使用 `overall_dimensions` 的长、宽、高。只有 `component` 才接收 `length_mm / width_mm / thickness_mm` 作为零件尺寸；柜体高度不会写成板厚。
- `procurement_reference_only: true` 标识采购参考行；`parent_reference` 保留所属柜体 / 用途。Web 默认先显示柜体 / 总成，可切换零件、材料、采购参考层级，避免混合层级累计。
- `quantity` 缺失保留 `null`。`quantity_unit` 保留来源单位，`quantity_basis` 说明整单 / 单套等口径，不将件、台、套、米混合求和。
- `evidence` 可保存 `source_path / file / page / sheet / row / cell / reference / quote / role`；页 / 行号采用从 1 开始的定位，也接受范围文字。
- `work_scopes` 支持木工、五金、油漆、玻璃、电工、装配、质检、包装，状态固定 `suggested`。
- 所有记录保持待复核、`draft_only: true`，工作范围不写入 `tasks`。审核、工艺生成与生产发布会阻断这些草稿，须另行细化并复核为真实生产 BOM。
- `GET /api/projects/{id}/export?format=json` 导出含来源、待核对项与工种范围的完整项目数据；草稿原文作为项目文档留存并计算 SHA256。

Web 中从“项目订单”打开对应项目，可查看“柜体与构件”“工种拆分”“待复核”“来源文件”“版本记录”。来源文件仅显示本地索引及页 / 单元格定位。
