# 项目完成与发货

项目有三个交付状态，与工程版本的“待复核 / 已发布”分别保存。

| 状态 | 派工与工牌 | 查看方式 |
|---|---|---|
| 进行中 | 可按原有复核与发布规则派工 | 项目订单默认列表 |
| 已完成 · 待发货 | 移出派工、工牌任务与人员待办 | 项目订单 → 已完成 |
| 已发货 | 移出派工、工牌任务与人员待办 | 项目订单 → 已发货 |

## 使用

1. 在项目订单卡片，或项目工作台顶部，打开“项目状态”。
2. 生产结束时选择“标记完成”；已实际发货时选择“标记已发货”。已完成项目可继续标记已发货。
3. 如果仍有未完工工序，系统列出工种、内容、状态、剩余数量和师傅姓名。核对后勾选“确认关单，未完工工序保留原进度并移出待办”，再确认。
4. 项目从进行中列表退出；在“已完成 / 已发货 / 全部”筛选中查看图纸、模型、任务和记录。
5. 误操作或需要继续生产时，通过“项目状态 → 重新打开项目”恢复。

关单不会把未完工任务自动记为完工，不修改累计数量、工程版本、暂停原因或交接记录。重新打开保留原进度；如果原负责人已开始另一项任务，系统提示先处理冲突，避免一个人同时占用两道进行中工序。

关闭期间，工程资料、构件、模型关联与项目外协费用不可修改；可继续查阅和导出。旧页面或直接 API 请求同样不能继续派工或下发工牌。已发货状态是本地项目记录，尚未关联物流单、签收、库存出库或 ERP 回写。

BI 的在途负载和待办排除已关闭项目，历史完成、报工与趋势记录保留。报价仍使用现有全局费率重新计算，不属于合同锁价或财务结算快照。
